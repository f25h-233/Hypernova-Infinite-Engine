# M0 Manifest 生成与覆盖率测量 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 用离线工具从 Base / 260mods 两个游戏根生成 L1/L2/L3 manifest，测出 L1 规模与覆盖率，为 M3 的启动期裁剪提供冻结输入。

**Architecture:** 全部是只读离线 Python 工具，位于 `tools/`，不进入游戏 jar。核心链路是 `宽松 JSON 解析 → 模组/资产索引 → 标题变体闭包（variant→hull/skin/weapon/wing/module→sprite）→ manifest 组装 → 校验 → 需求日志采集 → 覆盖率报告`。元数据优先用 `mods/DDSCache/*/dds_metadata.json`；DDSCache 为空时（Base 当前状态）自动降级为磁盘扫描 + 图片头探测。所有路径大小写不敏感、分隔符统一为正斜杠。

**Tech Stack:** Python 3.14.6（仅标准库），pytest 9.1.1，Git Bash；Java 不参与 M0（后续 Java 编译一律 `--release 17` + Base 原版 `starfarer.api.jar`）。

**Spec:** `技术笔记-纹理按需加载.md`（§5.3 接口、§5.4 manifest 模型、§7 M0、§9.1 环境矩阵、REQ-R1-04/05、附录 A 测量口径）。

## Global Constraints

- 工具运行方式固定为 `python -I tools/<name>.py ...`；测试为 `python -I -m pytest tests/tools -q`。
- 工具只读游戏目录，唯一写入口是 `--out`；M0 产物：`build/m0/`（manifest/demand，gitignored）+ `docs/m0/`（coverage 报告，入库）。
- 游戏数据一律 `encoding="utf-8-sig", errors="replace"`；写出的 JSON 用 `ensure_ascii=False`。
- 路径扫描一律用 `os.scandir` / `os.walk` / `pathlib`；**禁止**用带文件夹名的 `glob`（mod 文件夹含 `[]`、中文、空格）。
- 内部比较键统一 `\` → `/`、`casefold()`；输出保留原始大小写。
- 资源解析优先级：`enabled_mods.json` 顺序在前的 mod 优先，`starsector-core` 最后；冲突必须计数并写入 `stats.conflicts`。
- scope 固定口径：`all_mod_metadata` = 全部非 core metadata（78,350 条）；`mod_non_shader` = 再去掉 `GraphicsLib`/`shaderLib`（78,040 条）；`include_core=True` 追加 core 3,204 条。三组数不得混用。
- L1 出口：`closure_ref_coverage ≥ 0.95` 且 `l1_sprite_disk_coverage ≥ 0.95` 且 `l1_count ≤ 8000`。有 metadata 时额外要求 `metadata_coverage == 1.0`；无 metadata（Base 当前）此项记 N/A。
- 禁止 `git add -A` / `git add .`（仓库里有 8.4 GB 未跟踪的 `Starsector-098-260mods.7z`）；每个 commit 只加本任务明确列出的文件。
- Java 约束（本计划不涉及，但不得违反）：`--release 17`，只用 `Starsector-098-Base/starsector-core/starfarer.api.jar` 编译；260mods 那份被 AoD 替换的 api jar 不参与编译。
- **Escape hatch：** 若断言数字/测试顺序与实现不符，按实际修正并在 `task-N-report.md` 记录偏差；**若需求自相矛盾或无法同时满足 → 停下报告，不许挑一半照做。**

## Review Focus

1. **带 `[]`/中文/空格的 mod 文件夹** → 必须用 `os.scandir`；用 glob 会静默漏掉整个 mod。测试：fixture 里放 `mod_[x]` 和 `mod_中文`。
2. **StarSector JSON 方言** → `#`/`//`/`/* */` 注释、尾逗号、单引号、裸枚举值（`RENDER_LOADED_MISSILES`）、`;` 分隔、`+100`/`.97`/`1.`/`0x1F`/`1.0f`、文件尾多余 `}`。单文件解析失败必须记入 `parse_errors` 并继续，不能整批中止。
3. **缺失引用** → variant/hull/weapon/wing/sprite 各自分类计数；缺文件不是崩溃理由，但必须出现在 `stats.missing`。
4. **metadata 键不一致** → `RelativeImagePath` 用 `\`、大小写可能不同、mod 改名后目录不匹配；先按 `(folder, rel)` 精确匹配，再按 `rel` 唯一回退，回退次数入 stats。
5. **DDSCache 为空（Base）** → 必须走磁盘扫描 + PNG/JPEG/WebP/GIF 头探测；不得产出空 L1、不得因缺 metadata 抛异常。
6. **同 id/同路径冲突** → 同一 mod id 出现在多个文件夹、同一 asset 路径出现在多个 mod；必须按优先级选一个并记录全部候选。

```python
"""Starsector 方言 JSON 解析器。

本机实测（260mods 48,516 个 .json/.variant/.ship/.wpn/.system/.faction/.skill）
需要容忍的扩展：
  - '#'、'//' 行注释，'/* ... */' 块注释
  - 对象/数组尾逗号；';' 也可当分隔符
  - 单引号字符串；裸标识符值（如 RENDER_LOADED_MISSILES）
  - 数字：+100、.97、1.、0x1F、1.0f、033
  - 文件尾多余的 '}'/']'/','（游戏只读第一个值）

不支持：裸键里的空格、模板字符串。解析失败抛 ParseError。
"""
from __future__ import annotations

import re
from pathlib import Path

_BS = "\\"
_NUM = re.compile(
    r"[+-]?(?:(?:0[xX][0-9a-fA-F]+)|(?:\d+(?:\.\d*)?|\.\d+)(?:[eE][+-]?\d+)?)[fFdD]?"
)
_IDENT = re.compile(r"[A-Za-z0-9_$./%+*-]+")


class ParseError(ValueError):
    pass


class _Parser:
    def __init__(self, text: str):
        self.s = text
        self.i = 0
        self.n = len(text)

    def parse(self):
        self._ws()
        value = self._value()
        self._ws()
        while self.i < self.n and self.s[self.i] in ",;}];":
            self.i += 1
            self._ws()
        if self.i != self.n:
            raise ParseError(
                f"trailing data at offset {self.i}: {self.s[self.i:self.i + 40]!r}"
            )
        return value

    def _ws(self):
        while self.i < self.n:
            c = self.s[self.i]
            if c in " \t\r\n﻿":
                self.i += 1
            elif c == "#":
                while self.i < self.n and self.s[self.i] not in "\r\n":
                    self.i += 1
            elif c == "/" and self.i + 1 < self.n and self.s[self.i + 1] == "/":
                while self.i < self.n and self.s[self.i] not in "\r\n":
                    self.i += 1
            elif c == "/" and self.i + 1 < self.n and self.s[self.i + 1] == "*":
                end = self.s.find("*/", self.i + 2)
                if end < 0:
                    raise ParseError("unterminated block comment")
                self.i = end + 2
            else:
                return

    def _value(self):
        self._ws()
        if self.i >= self.n:
            raise ParseError("unexpected end of input")
        c = self.s[self.i]
        if c == "{":
            return self._object()
        if c == "[":
            return self._array()
        if c in "\"'":
            return self._string()
        if c in "-+." or c.isdigit():
            return self._number()
        if c.isalpha() or c in "_$":
            return self._identifier(as_key=False)
        raise ParseError(f"unexpected character {c!r} at offset {self.i}")

    def _object(self):
        self.i += 1
        out = {}
        self._ws()
        if self.i < self.n and self.s[self.i] == "}":
            self.i += 1
            return out
        while True:
            self._ws()
            if self.i >= self.n:
                raise ParseError("unterminated object")
            c = self.s[self.i]
            key = self._string() if c in "\"'" else self._identifier(as_key=True)
            self._ws()
            if self.i >= self.n or self.s[self.i] != ":":
                raise ParseError(f"expected ':' at offset {self.i}")
            self.i += 1
            out[key] = self._value()
            self._ws()
            if self.i < self.n and self.s[self.i] in ",;":
                self.i += 1
                self._ws()
                if self.i >= self.n:
                    return out
                if self.s[self.i] == "}":
                    self.i += 1
                    return out
                continue
            if self.i < self.n and self.s[self.i] == "}":
                self.i += 1
                return out
            raise ParseError(f"expected ',' or '}}' at offset {self.i}")

    def _array(self):
        self.i += 1
        out = []
        self._ws()
        if self.i < self.n and self.s[self.i] == "]":
            self.i += 1
            return out
        while True:
            out.append(self._value())
            self._ws()
            if self.i < self.n and self.s[self.i] in ",;":
                self.i += 1
                self._ws()
                if self.i >= self.n:
                    return out
                if self.s[self.i] == "]":
                    self.i += 1
                    return out
                continue
            if self.i < self.n and self.s[self.i] == "]":
                self.i += 1
                return out
            raise ParseError(f"expected ',' or ']' at offset {self.i}")

    def _string(self):
        quote = self.s[self.i]
        self.i += 1
        buf: list[str] = []
        escapes = {
            '"': '"',
            "'": "'",
            "\\": "\\",
            "/": "/",
            "b": "\b",
            "f": "\f",
            "n": "\n",
            "r": "\r",
            "t": "\t",
        }
        while self.i < self.n:
            c = self.s[self.i]
            if c == _BS:
                if self.i + 1 >= self.n:
                    raise ParseError("unterminated escape")
                esc = self.s[self.i + 1]
                if esc == "u":
                    hexs = self.s[self.i + 2:self.i + 6]
                    if len(hexs) == 4 and all(ch in "0123456789abcdefABCDEF" for ch in hexs):
                        buf.append(chr(int(hexs, 16)))
                        self.i += 6
                        continue
                    buf.append("u")
                    self.i += 2
                    continue
                buf.append(escapes.get(esc, esc))
                self.i += 2
                continue
            if c == quote:
                self.i += 1
                return "".join(buf)
            buf.append(c)
            self.i += 1
        raise ParseError("unterminated string")

    def _number(self):
        m = _NUM.match(self.s, self.i)
        if not m:
            raise ParseError(f"bad number at offset {self.i}")
        self.i = m.end()
        text = m.group(0).rstrip("fFdD")
        if text.lower().startswith(("0x", "+0x", "-0x")):
            return int(text, 16)
        if any(ch in text for ch in ".eE"):
            return float(text)
        return int(text)

    def _identifier(self, as_key: bool) -> str:
        m = _IDENT.match(self.s, self.i)
        if not m:
            raise ParseError(f"bad identifier at offset {self.i}")
        self.i = m.end()
        token = m.group(0)
        if not as_key:
            low = token.lower()
            if low == "true":
                return True
            if low == "false":
                return False
            if low == "null":
                return None
        return token


def loads(text: str):
    return _Parser(text).parse()


def load(path: str | Path):
    with open(path, encoding="utf-8-sig", errors="replace") as fh:
        return loads(fh.read())
```

```python
"""模组扫描、资产索引、标题 CSV、wing 表、DDS metadata。"""
from __future__ import annotations

import csv
import os
from dataclasses import dataclass, field
from pathlib import Path
from typing import Callable, Iterator

from hn_json import load

SHADER_LIBS = frozenset({"graphicslib", "shaderlib"})
CORE_FOLDER = "starsector-core"
IMAGE_SUFFIXES = frozenset({".png", ".jpg", ".jpeg", ".webp", ".gif"})


@dataclass(frozen=True)
class ModRef:
    mod_id: str
    folder: Path
    order: int
    is_core: bool = False


@dataclass(frozen=True)
class AssetRef:
    mod_id: str
    folder: Path
    absolute: Path
    rel: str
    order: int


@dataclass
class ModScan:
    mods: list[ModRef] = field(default_factory=list)
    missing_ids: list[str] = field(default_factory=list)
    duplicate_ids: dict[str, list[str]] = field(default_factory=dict)
    parse_errors: dict[str, str] = field(default_factory=dict)


@dataclass
class TitleVariants:
    ids: list[str] = field(default_factory=list)
    sources: dict[str, list[str]] = field(default_factory=dict)


@dataclass(frozen=True)
class MetadataEntry:
    mod_folder: str
    rel: str
    dds_rel: str
    width: int
    height: int


@dataclass
class MetadataIndex:
    entries: list[MetadataEntry] = field(default_factory=list)
    by_key: dict[tuple[str, str], MetadataEntry] = field(default_factory=dict)
    by_rel: dict[str, list[MetadataEntry]] = field(default_factory=dict)
    fallback_hits: int = 0
    parse_errors: dict[str, str] = field(default_factory=dict)

    def get(self, mod_folder: str, rel: str) -> MetadataEntry | None:
        key = (mod_folder.casefold(), rel.casefold())
        hit = self.by_key.get(key)
        if hit is not None:
            return hit
        candidates = self.by_rel.get(rel.casefold()) or []
        if len(candidates) == 1:
            self.fallback_hits += 1
            return candidates[0]
        return None


def _norm_rel(rel: str) -> str:
    out = rel.replace("\\", "/").lstrip("/")
    while "//" in out:
        out = out.replace("//", "/")
    return out


def load_enabled_ids(game_root: Path) -> list[str]:
    data = load(game_root / "mods" / "enabled_mods.json")
    ids = data.get("enabledMods") if isinstance(data, dict) else None
    if not isinstance(ids, list):
        raise ValueError("enabled_mods.json has no enabledMods list")
    return [str(x) for x in ids]


def scan_mods(game_root: Path, enabled_ids: list[str], include_core: bool = True) -> ModScan:
    mods_dir = game_root / "mods"
    by_id: dict[str, list[Path]] = {}
    parse_errors: dict[str, str] = {}
    with os.scandir(mods_dir) as it:
        entries = sorted(it, key=lambda e: e.name)
    for entry in entries:
        if not entry.is_dir() or entry.name == "DDSCache":
            continue
        info = Path(entry.path) / "mod_info.json"
        if not info.is_file():
            continue
        try:
            data = load(info)
            mid = data.get("id")
        except Exception as exc:
            parse_errors[entry.name] = str(exc)
            continue
        if mid:
            by_id.setdefault(str(mid), []).append(Path(entry.path))
    duplicate_ids = {
        mid: sorted(p.name for p in paths) for mid, paths in by_id.items() if len(paths) > 1
    }
    scan = ModScan(duplicate_ids=duplicate_ids, parse_errors=parse_errors)
    for order, mid in enumerate(enabled_ids):
        folders = by_id.get(mid)
        if not folders:
            scan.missing_ids.append(mid)
            continue
        scan.mods.append(ModRef(mid, sorted(folders)[0], order))
    if include_core:
        core = game_root / CORE_FOLDER
        if core.is_dir():
            scan.mods.append(ModRef("core", core, len(enabled_ids), True))
    return scan


def iter_assets(mod: ModRef, subdir: str, suffixes: frozenset[str]) -> Iterator[AssetRef]:
    base = mod.folder / "data" / subdir
    if not base.is_dir():
        return
    for dirpath, _dirnames, filenames in os.walk(base):
        for fn in filenames:
            if Path(fn).suffix.casefold() not in suffixes:
                continue
            absolute = Path(dirpath) / fn
            rel = absolute.relative_to(mod.folder).as_posix()
            yield AssetRef(mod.mod_id, mod.folder, absolute, rel, mod.order)


def build_index(
    mods: list[ModRef],
    subdir: str,
    suffixes: frozenset[str],
    key: Callable[[AssetRef], str] | None = None,
) -> dict[str, list[AssetRef]]:
    index: dict[str, list[AssetRef]] = {}
    for mod in mods:
        for asset in iter_assets(mod, subdir, suffixes):
            k = key(asset) if key else Path(asset.rel).stem
            index.setdefault(k, []).append(asset)
    return index


def build_id_index(
    mods: list[ModRef],
    subdir: str,
    suffixes: frozenset[str],
    id_field: str,
    extra_subdirs: tuple[str, ...] = (),
) -> dict[str, list[AssetRef]]:
    """按文件名 stem 与内部 id 双键索引；内部 id 不符时仍可按文件名命中。"""
    index: dict[str, list[AssetRef]] = {}
    for current in (subdir, *extra_subdirs):
        for mod in mods:
            for asset in iter_assets(mod, current, suffixes):
                try:
                    data = load(asset.absolute)
                except Exception:
                    data = {}
                keys = {Path(asset.rel).stem}
                internal = data.get(id_field) if isinstance(data, dict) else None
                if isinstance(internal, str) and internal.strip():
                    keys.add(internal.strip())
                for key in keys:
                    index.setdefault(key, []).append(asset)
    return index


def build_image_index(mods: list[ModRef]) -> dict[str, list[AssetRef]]:
    index: dict[str, list[AssetRef]] = {}
    for mod in mods:
        for dirpath, _dirnames, filenames in os.walk(mod.folder):
            for fn in filenames:
                if Path(fn).suffix.casefold() not in IMAGE_SUFFIXES:
                    continue
                absolute = Path(dirpath) / fn
                rel = absolute.relative_to(mod.folder).as_posix()
                index.setdefault(rel.casefold(), []).append(
                    AssetRef(mod.mod_id, mod.folder, absolute, rel, mod.order)
                )
    return index


def pick(candidates: list[AssetRef]) -> AssetRef | None:
    if not candidates:
        return None
    return min(candidates, key=lambda a: (a.order, a.absolute.as_posix().casefold()))


def read_title_variants(mods: list[ModRef]) -> TitleVariants:
    tv = TitleVariants()
    for mod in mods:
        path = mod.folder / "data" / "config" / "title_screen_variants.csv"
        if not path.is_file():
            continue
        text = path.read_text(encoding="utf-8-sig", errors="replace")
        for line in text.splitlines():
            line = line.strip()
            if not line or line.startswith("#"):
                continue
            value = line.split(",", 1)[0].strip().strip('"').strip()
            if not value or value.casefold().startswith("variant"):
                continue
            if value not in tv.sources:
                tv.ids.append(value)
                tv.sources[value] = []
            tv.sources[value].append(mod.mod_id)
    return tv


def read_wing_map(mods: list[ModRef]) -> dict[str, str]:
    wings: dict[str, str] = {}
    for mod in mods:
        path = mod.folder / "data" / "hulls" / "wing_data.csv"
        if not path.is_file():
            continue
        with path.open(encoding="utf-8-sig", errors="replace", newline="") as fh:
            for row in csv.reader(fh):
                if len(row) < 2:
                    continue
                wid = row[0].strip().strip('"')
                vid = row[1].strip().strip('"')
                if not wid or wid.startswith("#") or wid.casefold() == "id" or not vid:
                    continue
                wings.setdefault(wid, vid)
    return wings


def read_dds_metadata(game_root: Path) -> MetadataIndex:
    index = MetadataIndex()
    cache = game_root / "mods" / "DDSCache"
    if not cache.is_dir():
        return index
    with os.scandir(cache) as it:
        entries = sorted(it, key=lambda e: e.name)
    for entry in entries:
        if not entry.is_dir():
            continue
        path = Path(entry.path) / "dds_metadata.json"
        if not path.is_file():
            continue
        try:
            records = load(path)
        except Exception as exc:
            index.parse_errors[entry.name] = f"{path.name}: {exc}"
            continue
        if not isinstance(records, list):
            index.parse_errors[entry.name] = f"{path.name}: top-level is not a list"
            continue
        for lineno, record in enumerate(records, 1):
            try:
                if not isinstance(record, dict):
                    raise ValueError("record is not an object")
                folder = str(record.get("ModFolderName") or entry.name)
                rel = _norm_rel(str(record.get("RelativeImagePath") or ""))
                if not rel:
                    raise ValueError("empty RelativeImagePath")
                dds_rel = _norm_rel(str(record.get("DDSFilePath") or ""))
                me = MetadataEntry(
                    folder,
                    rel,
                    dds_rel,
                    int(record.get("Width") or 0),
                    int(record.get("Height") or 0),
                )
            except Exception as exc:
                index.parse_errors[entry.name] = f"{path.name} record {lineno}: {exc}"
                continue
            index.entries.append(me)
            index.by_key[(folder.casefold(), rel.casefold())] = me
            index.by_rel.setdefault(rel.casefold(), []).append(me)
    return index


def in_scope(me: MetadataEntry, scope: str) -> bool:
    folder = me.mod_folder.casefold()
    if scope == "all_mod_metadata":
        return folder != CORE_FOLDER
    if scope == "mod_non_shader":
        return folder != CORE_FOLDER and folder not in SHADER_LIBS
    raise ValueError(f"unknown scope: {scope}")


def folder_in_scope(folder_name: str, scope: str) -> bool:
    folder = folder_name.casefold()
    if scope == "all_mod_metadata":
        return folder != CORE_FOLDER
    if scope == "mod_non_shader":
        return folder != CORE_FOLDER and folder not in SHADER_LIBS
    raise ValueError(f"unknown scope: {scope}")
```

```python
"""从标题 variant 集合展开出全部 sprite 路径（递归 modules/wings/skins）。"""
from __future__ import annotations

from dataclasses import dataclass, field
from pathlib import Path

from hn_json import load
from mod_index import AssetRef, ModRef, build_image_index, build_index, pick, read_wing_map

WEAPON_SPRITE_FIELDS = (
    "turretSprite",
    "hardpointSprite",
    "turretGlowSprite",
    "hardpointGlowSprite",
    "turretGunSprite",
    "hardpointGunSprite",
    "turretUnderSprite",
    "hardpointUnderSprite",
)


@dataclass(frozen=True)
class SpriteRef:
    rel: str
    owner: AssetRef | None


@dataclass
class ClosureStats:
    variants_total: int = 0
    variants_resolved: int = 0
    hulls_total: int = 0
    hulls_resolved: int = 0
    weapons_total: int = 0
    weapons_resolved: int = 0
    wings_total: int = 0
    wings_resolved: int = 0
    missing: dict[str, list[str]] = field(default_factory=dict)
    parse_errors: dict[str, list[str]] = field(default_factory=dict)

    def miss(self, kind: str, name: str) -> None:
        self.missing.setdefault(kind, []).append(name)

    def parse_fail(self, kind: str, name: str) -> None:
        self.parse_errors.setdefault(kind, []).append(name)


@dataclass
class ClosureResult:
    sprites: dict[str, SpriteRef] = field(default_factory=dict)
    stats: ClosureStats = field(default_factory=ClosureStats)


@dataclass
class AssetLookup:
    variants: dict[str, list[AssetRef]]
    ships: dict[str, list[AssetRef]]
    skins: dict[str, list[AssetRef]]
    weapons: dict[str, list[AssetRef]]
    images: dict[str, list[AssetRef]]
    wings: dict[str, str]


def _build_skin_index(mods: list[ModRef]) -> dict[str, list[AssetRef]]:
    out: dict[str, list[AssetRef]] = {}
    for mod in mods:
        base = mod.folder / "data" / "hulls"
        if not base.is_dir():
            continue
        import os

        for dirpath, _dirnames, filenames in os.walk(base):
            for fn in filenames:
                if Path(fn).suffix.casefold() != ".skin":
                    continue
                absolute = Path(dirpath) / fn
                try:
                    data = load(absolute)
                except Exception:
                    continue
                sid = str(data.get("skinHullId") or Path(fn).stem)
                rel = absolute.relative_to(mod.folder).as_posix()
                out.setdefault(sid, []).append(
                    AssetRef(mod.mod_id, mod.folder, absolute, rel, mod.order)
                )
    return out


def build_lookup(mods: list[ModRef]) -> AssetLookup:
    return AssetLookup(
        variants=build_index(mods, "variants", frozenset({".variant"})),
        ships=build_index(mods, "hulls", frozenset({".ship"})),
        skins=_build_skin_index(mods),
        weapons=build_index(mods, "weapons", frozenset({".wpn"})),
        images=build_image_index(mods),
        wings=read_wing_map(mods),
    )


def _norm_path(value) -> str | None:
    if not isinstance(value, str) or not value.strip():
        return None
    return value.replace("\\", "/").lstrip("/")


class _Walker:
    def __init__(self, lookup: AssetLookup):
        self.lookup = lookup
        self.result = ClosureResult()
        self._variants: set[str] = set()
        self._hulls: set[str] = set()
        self._weapons: set[str] = set()
        self._wings: set[str] = set()

    def add_sprite(self, value) -> None:
        rel = _norm_path(value)
        if not rel:
            return
        key = rel.casefold()
        if key in self.result.sprites:
            return
        owner = pick(self.lookup.images.get(key) or [])
        self.result.sprites[key] = SpriteRef(rel, owner)

    def add_weapon(self, wid) -> None:
        if not isinstance(wid, str) or not wid:
            return
        if wid in self._weapons:
            return
        self._weapons.add(wid)
        self.result.stats.weapons_total += 1
        asset = pick(self.lookup.weapons.get(wid) or [])
        if asset is None:
            self.result.stats.miss("weapon", wid)
            return
        self.result.stats.weapons_resolved += 1
        try:
            data = load(asset.absolute)
        except Exception:
            self.result.stats.parse_fail("weapon", wid)
            return
        for name in WEAPON_SPRITE_FIELDS:
            self.add_sprite(data.get(name))

    def add_hull(self, hid) -> None:
        if not isinstance(hid, str) or not hid:
            return
        if hid in self._hulls:
            return
        self._hulls.add(hid)
        self.result.stats.hulls_total += 1
        skin = pick(self.lookup.skins.get(hid) or [])
        ship = pick(self.lookup.ships.get(hid) or [])
        if skin is None and ship is None:
            self.result.stats.miss("hull", hid)
            return
        self.result.stats.hulls_resolved += 1
        skin_data = {}
        if skin is not None:
            try:
                skin_data = load(skin.absolute)
            except Exception:
                self.result.stats.parse_fail("skin", hid)
            else:
                self.add_sprite(skin_data.get("spriteName"))
                self._builtins(skin_data)
                base_id = skin_data.get("baseHullId")
                if isinstance(base_id, str):
                    base = pick(self.lookup.ships.get(base_id) or [])
                    if base is not None:
                        try:
                            base_data = load(base.absolute)
                        except Exception:
                            base_data = {}
                        if not skin_data.get("spriteName"):
                            self.add_sprite(base_data.get("spriteName"))
                        self._builtins(base_data)
        if ship is not None:
            try:
                ship_data = load(ship.absolute)
            except Exception:
                self.result.stats.parse_fail("hull", hid)
                return
            self.add_sprite(ship_data.get("spriteName"))
            self._builtins(ship_data)
            if str(ship_data.get("hullSize") or "").upper() == "FIGHTER":
                self._wings.add(hid)

    def _builtins(self, data: dict) -> None:
        weapons = data.get("builtInWeapons") or {}
        if isinstance(weapons, dict):
            for wid in weapons.values():
                self.add_weapon(wid)
        elif isinstance(weapons, list):
            for wid in weapons:
                self.add_weapon(wid)
        wings = data.get("builtInWings") or []
        if isinstance(wings, list):
            for wing in wings:
                self.add_wing(wing)

    def add_wing(self, wing_id) -> None:
        if not isinstance(wing_id, str) or not wing_id:
            return
        if wing_id in self._wings:
            return
        self._wings.add(wing_id)
        self.result.stats.wings_total += 1
        variant_id = self.lookup.wings.get(wing_id)
        if variant_id:
            self.result.stats.wings_resolved += 1
            self.add_variant(variant_id)
            return
        # 少数 mod 直接把 wing 写成 hull id
        if wing_id in self.lookup.ships or wing_id in self.lookup.skins:
            self.result.stats.wings_resolved += 1
            self.add_hull(wing_id)
            return
        self.result.stats.miss("wing", wing_id)

    def add_variant(self, vid) -> None:
        if not isinstance(vid, str) or not vid:
            return
        if vid in self._variants:
            return
        self._variants.add(vid)
        self.result.stats.variants_total += 1
        asset = pick(self.lookup.variants.get(vid) or [])
        if asset is None:
            self.result.stats.miss("variant", vid)
            return
        try:
            data = load(asset.absolute)
        except Exception:
            self.result.stats.parse_fail("variant", vid)
            return
        self.result.stats.variants_resolved += 1
        self.add_hull(data.get("hullId"))
        for group in data.get("weaponGroups") or []:
            if isinstance(group, dict):
                for wid in (group.get("weapons") or {}).values():
                    self.add_weapon(wid)
        modules = data.get("modules") or []
        if isinstance(modules, dict):
            modules = [modules]
        for module in modules:
            if isinstance(module, dict):
                for ref in module.values():
                    self.add_variant(ref)
        for wing in data.get("wings") or []:
            self.add_wing(wing)


def build_closure(variant_ids: list[str], lookup: AssetLookup) -> ClosureResult:
    walker = _Walker(lookup)
    for vid in variant_ids:
        walker.add_variant(vid)
    for key in ("missing", "parse_errors"):
        bucket = getattr(walker.result.stats, key)
        for names in bucket.values():
            names.sort()
    return walker.result
```

```python
"""只读文件头拿尺寸，不解码像素。"""
from __future__ import annotations

import struct
from pathlib import Path

_PNG_SIG = b"\x89PNG\r\n\x1a\n"


def _png(data: bytes) -> tuple[int, int]:
    if len(data) < 24 or not data.startswith(_PNG_SIG):
        return (0, 0)
    w, h = struct.unpack(">II", data[16:24])
    return (int(w), int(h))


def _gif(data: bytes) -> tuple[int, int]:
    if len(data) < 10:
        return (0, 0)
    w, h = struct.unpack("<HH", data[6:10])
    return (int(w), int(h))


def _jpeg(data: bytes) -> tuple[int, int]:
    i = 2
    n = len(data)
    while i + 9 < n:
        if data[i] != 0xFF:
            i += 1
            continue
        marker = data[i + 1]
        if marker in (0xD8, 0xD9):
            i += 2
            continue
        if i + 4 > n:
            break
        length = struct.unpack(">H", data[i + 2:i + 4])[0]
        if marker in (0xC0, 0xC1, 0xC2, 0xC3, 0xC5, 0xC6, 0xC7, 0xC9, 0xCA, 0xCB, 0xCD, 0xCE, 0xCF):
            if i + 9 <= n:
                h, w = struct.unpack(">HH", data[i + 5:i + 9])
                return (int(w), int(h))
            return (0, 0)
        if length < 2:
            break
        i += 2 + length
    return (0, 0)


def _webp(data: bytes) -> tuple[int, int]:
    if len(data) < 30 or data[:4] != b"RIFF" or data[8:12] != b"WEBP":
        return (0, 0)
    chunk = data[12:16]
    if chunk == b"VP8X" and len(data) >= 30:
        w = 1 + int.from_bytes(data[24:27], "little")
        h = 1 + int.from_bytes(data[27:30], "little")
        return (w, h)
    if chunk == b"VP8L" and len(data) >= 25:
        bits = int.from_bytes(data[21:25], "little")
        return (1 + (bits & 0x3FFF), 1 + ((bits >> 14) & 0x3FFF))
    if chunk == b"VP8 " and len(data) >= 30:
        w = int.from_bytes(data[26:28], "little") & 0x3FFF
        h = int.from_bytes(data[28:30], "little") & 0x3FFF
        return (w, h)
    return (0, 0)


def probe(path: Path) -> tuple[int, int]:
    try:
        with open(path, "rb") as fh:
            data = fh.read(262144)
    except OSError:
        return (0, 0)
    suffix = path.suffix.casefold()
    if suffix == ".png":
        return _png(data)
    if suffix == ".gif":
        return _gif(data)
    if suffix in (".jpg", ".jpeg"):
        return _jpeg(data)
    if suffix == ".webp":
        return _webp(data)
    return (0, 0)
```

```python
        try:
```

```python
"""把 core 资产 + 标题闭包 + 全量实体池 + 元数据余量组装成 manifest。"""
from __future__ import annotations

from dataclasses import dataclass, field
from datetime import datetime
from pathlib import Path

from image_probe import probe
from l1_core import core_assets
from mod_index import (
    MetadataEntry,
    MetadataIndex,
    folder_in_scope,
    in_scope,
    load_enabled_ids,
    pick,
    read_dds_metadata,
    read_title_variants,
    scan_mods,
)
from sprite_closure import AssetLookup, build_closure, build_lookup

SCHEMA = 1


@dataclass
class BuildResult:
    manifest: dict
    warnings: list[str] = field(default_factory=list)


def _folder_path(game_root: Path, folder: str) -> Path:
    if folder.casefold() == "starsector-core":
        return game_root / "starsector-core"
    return game_root / "mods" / folder


def _entry(
    mod_id: str,
    path: str,
    absolute: str,
    dds: str | None,
    w: int,
    h: int,
    baked: bool,
    src: str,
) -> dict:
    return {
        "modId": mod_id,
        "path": path,
        "absolutePath": absolute,
        "ddsPath": dds,
        "w": int(w),
        "h": int(h),
        "baked": bool(baked),
        "src": src,
    }


def _sprite_entry(
    rel: str,
    lookup: AssetLookup,
    metadata: MetadataIndex,
    game_root: Path,
) -> tuple[dict, tuple[str, str] | None]:
    owner = pick(lookup.images.get(rel.casefold()) or [])
    meta: MetadataEntry | None = None
    if owner is not None:
        meta = metadata.get(owner.folder.name, rel)
    else:
        candidates = metadata.by_rel.get(rel.casefold()) or []
        if len(candidates) == 1:
            meta = candidates[0]

    if owner is not None:
        absolute = owner.absolute.as_posix()
        mod_id = owner.mod_id
    elif meta is not None:
        absolute = (_folder_path(game_root, meta.mod_folder) / meta.rel).as_posix()
        mod_id = "core" if meta.mod_folder.casefold() == "starsector-core" else meta.mod_folder
    else:
        absolute = ""
        mod_id = "unknown"

    dds = None
    w = h = 0
    baked = False
    src = "spec_scan"
    if meta is not None:
        baked = True
        src = "dds_metadata"
        w, h = meta.width, meta.height
        if meta.dds_rel:
            dds = (game_root / meta.dds_rel).as_posix()
    elif owner is not None:
        w, h = probe(owner.absolute)
        src = "header_probe" if w and h else "spec_scan"

    owner_key = None
    if owner is not None:
        owner_key = (owner.folder.name.casefold(), rel.casefold())
    elif meta is not None:
        owner_key = (meta.mod_folder.casefold(), meta.rel.casefold())
    return _entry(mod_id, rel, absolute, dds, w, h, baked, src), owner_key


def _metadata_entry(me: MetadataEntry, game_root: Path, folder_to_id: dict[str, str]) -> dict:
    absolute = (_folder_path(game_root, me.mod_folder) / me.rel).as_posix()
    dds = (game_root / me.dds_rel).as_posix() if me.dds_rel else None
    if me.mod_folder.casefold() == "starsector-core":
        mod_id = "core"
    else:
        mod_id = folder_to_id.get(me.mod_folder.casefold(), me.mod_folder)
    return _entry(
        mod_id,
        me.rel,
        absolute,
        dds,
        me.width,
        me.height,
        True,
        "dds_metadata",
    )


def build_manifest(
    game_root: Path,
    scope: str = "mod_non_shader",
    include_core: bool = True,
    include_l2: bool = True,
    variant_limit: int = 0,
) -> BuildResult:
    enabled = load_enabled_ids(game_root)
    scan = scan_mods(game_root, enabled, include_core=True)
    lookup = build_lookup(scan.mods)
    title = read_title_variants(scan.mods)
    metadata = read_dds_metadata(game_root)

    l1: list[dict] = []
    seen_paths: set[str] = set()
    seen_meta: set[tuple[str, str]] = set()

    def add_sprite(rel: str) -> None:
        key = rel.casefold()
        if key in seen_paths:
            return
        seen_paths.add(key)
        entry, owner_key = _sprite_entry(rel, lookup, metadata, game_root)
        l1.append(entry)
        if owner_key:
            seen_meta.add(owner_key)

    for rel in core_assets(game_root):
        add_sprite(rel)

    title_closure = build_closure(title.ids, lookup)
    for ref in title_closure.sprites.values():
        add_sprite(ref.rel)

    l2: list[dict] = []
    if include_l2:
        variants = sorted(lookup.variants)
        if variant_limit and variant_limit > 0:
            variants = variants[:variant_limit]
        pool = build_closure(variants, lookup)
        for ref in pool.sprites.values():
            key = ref.rel.casefold()
            if key in seen_paths:
                continue
            seen_paths.add(key)
            entry, owner_key = _sprite_entry(ref.rel, lookup, metadata, game_root)
            l2.append(entry)
            if owner_key:
                seen_meta.add(owner_key)

    l3: list[dict] = []
    folder_to_id = {m.folder.name.casefold(): m.mod_id for m in scan.mods}
    scope_meta = [me for me in metadata.entries if in_scope(me, scope)]
    core_meta = (
        [me for me in metadata.entries if me.mod_folder.casefold() == "starsector-core"]
        if include_core
        else []
    )
    for me in scope_meta + core_meta:
        key = (me.mod_folder.casefold(), me.rel.casefold())
        if key in seen_meta:
            continue
        seen_meta.add(key)
        l3.append(_metadata_entry(me, game_root, folder_to_id))

    scope_images = []
    core_images = []
    for assets in lookup.images.values():
        for asset in assets:
            if asset.mod_id == "core":
                if include_core:
                    core_images.append(asset)
            elif folder_in_scope(asset.folder.name, scope):
                scope_images.append(asset)
    meta_keys = {
        (me.mod_folder.casefold(), me.rel.casefold())
        for me in scope_meta + core_meta
    }
    for asset in scope_images + core_images:
        key = (asset.folder.name.casefold(), asset.rel.casefold())
        if key in meta_keys or asset.rel.casefold() in seen_paths:
            continue
        w, h = probe(asset.absolute)
        l3.append(
            _entry(
                asset.mod_id,
                asset.rel,
                asset.absolute.as_posix(),
                None,
                w,
                h,
                False,
                "header_probe" if w and h else "spec_scan",
            )
        )

    l1_disk = sum(
        1 for e in l1 if e["absolutePath"] and Path(e["absolutePath"]).is_file()
    )
    l1_baked = sum(1 for e in l1 if e["baked"])
    refs_total = sum(
        getattr(title_closure.stats, name)
        for name in (
            "variants_total",
            "hulls_total",
            "weapons_total",
            "wings_total",
        )
    )
    refs_ok = sum(
        getattr(title_closure.stats, name)
        for name in (
            "variants_resolved",
            "hulls_resolved",
            "weapons_resolved",
            "wings_resolved",
        )
    )
    meta_total = len(scope_meta)
    meta_all = len(scope_meta) + len(core_meta)
    meta_seen = sum(
        1
        for me in scope_meta + core_meta
        if (me.mod_folder.casefold(), me.rel.casefold()) in seen_meta
    )
    disk_images = len(scope_images)
    unbaked = 0
    for asset in scope_images:
        if metadata.get(asset.folder.name, asset.rel) is None:
            unbaked += 1

    closure_stats = title_closure.stats
    manifest = {
        "schema": SCHEMA,
        "generated_at": datetime.now().astimezone().isoformat(timespec="seconds"),
        "baseline": {
            "game": "0.98a-RC8",
            "fr": None,
            "enabled_mods": len(enabled),
        },
        "scope": scope,
        "include_core": include_core,
        "layers": {"L1": l1, "L2": l2, "L3": l3},
        "stats": {
            "scope": scope,
            "include_core": include_core,
            "metadata_entries": meta_total,
            "baked": meta_total,
            "unbaked": unbaked,
            "disk_images": disk_images,
            "core_entries": len(core_meta),
            "l1_count": len(l1),
            "l2_count": len(l2),
            "l3_count": len(l3),
            "closure": {
                "variants": [closure_stats.variants_total, closure_stats.variants_resolved],
                "hulls": [closure_stats.hulls_total, closure_stats.hulls_resolved],
                "weapons": [closure_stats.weapons_total, closure_stats.weapons_resolved],
                "wings": [closure_stats.wings_total, closure_stats.wings_resolved],
            },
            "coverage": {
                "l1_sprite_disk": (l1_disk / len(l1)) if l1 else 1.0,
                "l1_baked": (l1_baked / len(l1)) if l1 else 1.0,
                "closure_refs": (refs_ok / refs_total) if refs_total else 1.0,
                "metadata": (
                    0.0
                    if metadata.parse_errors
                    else ((meta_seen / meta_all) if meta_all else None)
                ),
            },
            "missing": closure_stats.missing,
            "parse_errors": closure_stats.parse_errors,
            "conflicts": {
                "duplicate_mod_ids": scan.duplicate_ids,
                "mod_parse_errors": scan.parse_errors,
                "missing_mod_ids": scan.missing_ids,
            },
            "metadata_fallback_hits": metadata.fallback_hits,
            "metadata_parse_errors": metadata.parse_errors,
            "source_mode": "disk_scan" if meta_all == 0 else "dds_metadata",
            "precedence": "enabled_order_then_core",
        },
    }
    warnings = []
    if scan.missing_ids:
        warnings.append(f"missing mods: {scan.missing_ids}")
    if scan.duplicate_ids:
        warnings.append(f"duplicate mod ids: {scan.duplicate_ids}")
    return BuildResult(manifest, warnings)
```

```python
#!/usr/bin/env python3
"""校验 manifest 的结构、路径存在性、覆盖率与 L1 规模。"""
from __future__ import annotations

import argparse
import json
import sys
from dataclasses import dataclass
from pathlib import Path

REQUIRED_ENTRY = ("modId", "path", "absolutePath", "ddsPath", "w", "h", "baked", "src")


@dataclass(frozen=True)
class Finding:
    severity: str
    code: str
    message: str


def _entry_findings(entry: dict, layer: str, game_root: Path) -> list[Finding]:
    out: list[Finding] = []
    missing = [k for k in REQUIRED_ENTRY if k not in entry]
    if missing:
        return [Finding("Critical", "entry_schema", f"{layer}: missing keys {missing}")]
    path = str(entry["path"])
    if not path or path.startswith("/") or ".." in path.split("/"):
        out.append(Finding("Critical", "bad_path", f"{layer}: illegal path {path!r}"))
    absolute = str(entry["absolutePath"])
    if not absolute:
        out.append(
            Finding("Critical", "missing_file", f"{layer}: unresolved asset {path}")
        )
    elif not Path(absolute).is_file():
        out.append(
            Finding("Critical", "missing_file", f"{layer}: file not found {absolute}")
        )
    if entry["baked"]:
        dds = entry.get("ddsPath")
        if not dds or not Path(str(dds)).is_file():
            out.append(
                Finding("Critical", "missing_dds", f"{layer}: baked entry has no DDS {path}")
            )
    if int(entry["w"]) < 0 or int(entry["h"]) < 0:
        out.append(Finding("Minor", "bad_size", f"{layer}: negative size {path}"))
    return out


def validate(
    manifest: dict,
    game_root: Path,
    min_coverage: float = 0.95,
    max_l1: int = 8000,
) -> list[Finding]:
    findings: list[Finding] = []
    if manifest.get("schema") != 1:
        findings.append(
            Finding("Critical", "schema", f"expected schema 1, got {manifest.get('schema')}")
        )
    layers = manifest.get("layers")
    if not isinstance(layers, dict) or not all(k in layers for k in ("L1", "L2", "L3")):
        findings.append(Finding("Critical", "layers", "layers must contain L1/L2/L3"))
        return findings
    for name in ("L1", "L2", "L3"):
        entries = layers[name]
        if not isinstance(entries, list):
            findings.append(Finding("Critical", "layers", f"{name} is not a list"))
            continue
        seen = set()
        for entry in entries:
            findings.extend(_entry_findings(entry, name, game_root))
            key = (str(entry.get("modId")), str(entry.get("path")).casefold())
            if key in seen:
                findings.append(
                    Finding("Important", "duplicate_entry", f"{name}: duplicate {key}")
                )
            seen.add(key)

    stats = manifest.get("stats") or {}
    coverage = stats.get("coverage") or {}
    l1_count = int(stats.get("l1_count") or len(layers["L1"]))
    if l1_count > max_l1:
        findings.append(
            Finding("Critical", "l1_too_large", f"L1={l1_count} > {max_l1}")
        )
    for key in ("l1_sprite_disk", "closure_refs"):
        value = coverage.get(key)
        if value is not None and float(value) < min_coverage:
            findings.append(
                Finding(
                    "Critical",
                    f"coverage_{key}",
                    f"{key}={value} < {min_coverage}",
                )
            )
    meta_cov = coverage.get("metadata")
    if meta_cov is not None and float(meta_cov) < 1.0:
        findings.append(
            Finding("Important", "coverage_metadata", f"metadata={meta_cov} < 1.0")
        )
    parse_errors = stats.get("metadata_parse_errors") or {}
    if parse_errors:
        findings.append(
            Finding(
                "Critical",
                "metadata_parse_errors",
                f"{len(parse_errors)} metadata file(s) failed to parse: "
                + ", ".join(sorted(parse_errors)[:5]),
            )
        )
    return findings


def main(argv: list[str] | None = None) -> int:
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("--manifest", required=True, type=Path)
    parser.add_argument("--game-root", required=True, type=Path)
    parser.add_argument("--min-coverage", type=float, default=0.95)
    parser.add_argument("--max-l1", type=int, default=8000)
    parser.add_argument("--json", action="store_true")
    args = parser.parse_args(argv)
    manifest = json.loads(args.manifest.read_text(encoding="utf-8"))
    findings = validate(manifest, args.game_root, args.min_coverage, args.max_l1)
    if args.json:
        print(json.dumps([f.__dict__ for f in findings], ensure_ascii=False, indent=2))
    else:
        for f in findings:
            print(f"[{f.severity}] {f.code}: {f.message}")
        if not findings:
            print("OK: no findings")
    return 1 if any(f.severity == "Critical" for f in findings) else 0


if __name__ == "__main__":
    raise SystemExit(main())
```

```python
#!/usr/bin/env python3
"""把 starsector.log 的首屏 PNG 加载行采成 demand.jsonl。"""
from __future__ import annotations

import argparse
import json
import re
from collections import Counter
from pathlib import Path

BANNER = "正在运行 Starsector"
IMG_RE = re.compile(r"Loading image \[([^\]]*)\]")
THREAD_RE = re.compile(r"^\d+\s+\[([^\]]+)\]")
MS_RE = re.compile(r"^(\d+)\s")
ANCHOR_CLASS = "CodexTextEntryLoader"
ANCHOR_TEXT = "Parsing entry"


def read_sessions(path: Path) -> list[tuple[int, int]]:
    starts = []
    total = 0
    with path.open("r", encoding="utf-8", errors="replace") as fh:
        for lineno, line in enumerate(fh, 1):
            total = lineno
            if BANNER in line:
                starts.append(lineno)
    if not starts:
        return []
    out = []
    for i, start in enumerate(starts):
        end = starts[i + 1] - 1 if i + 1 < len(starts) else total
        out.append((start, end))
    return out


def collect_session(
    path: Path, start: int, end: int, until_anchor: bool = True
) -> tuple[list[dict], dict]:
    records: list[dict] = []
    threads: Counter[str] = Counter()
    anchor_ms = None
    with path.open("r", encoding="utf-8", errors="replace") as fh:
        for lineno, line in enumerate(fh, 1):
            if lineno < start:
                continue
            if lineno > end:
                break
            ms = None
            m = MS_RE.match(line)
            if m:
                ms = int(m.group(1))
            if until_anchor and ANCHOR_CLASS in line and ANCHOR_TEXT in line:
                anchor_ms = ms
                break
            m = IMG_RE.search(line)
            if not m:
                continue
            thread = ""
            tm = THREAD_RE.match(line)
            if tm:
                thread = tm.group(1)
            threads[thread] += 1
            records.append(
                {
                    "session": 0,
                    "line": lineno,
                    "ms": ms,
                    "thread": thread,
                    "path": m.group(1).replace("\\", "/"),
                }
            )
    summary = {
        "anchor_ms": anchor_ms,
        "records": len(records),
        "unique_paths": len({r["path"] for r in records}),
        "threads": dict(threads),
    }
    return records, summary


def collect(
    path: Path, session: int | None = None, until_anchor: bool = True
) -> tuple[list[dict], dict]:
    sessions = read_sessions(path)
    if not sessions:
        return [], {"sessions": 0, "records": 0, "unique_paths": 0, "anchor_ms": None}
    selected = (
        [(session, sessions[session - 1])]
        if session is not None
        else list(enumerate(sessions, 1))
    )
    all_records: list[dict] = []
    anchors = {}
    total_threads: Counter[str] = Counter()
    for number, (start, end) in selected:
        records, summary = collect_session(path, start, end, until_anchor)
        for record in records:
            record["session"] = number
        all_records.extend(records)
        total_threads.update(summary["threads"])
        if summary["anchor_ms"] is not None:
            anchors[number] = summary["anchor_ms"]
    return all_records, {
        "sessions": len(selected),
        "records": len(all_records),
        "unique_paths": len({r["path"] for r in all_records}),
        "anchor_ms": anchors if session is None else anchors.get(session),
        "threads": dict(total_threads),
    }


def main(argv: list[str] | None = None) -> int:
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("--log", required=True, type=Path)
    parser.add_argument("--out", required=True, type=Path)
    parser.add_argument("--session", type=int, default=None)
    parser.add_argument("--json", action="store_true")
    args = parser.parse_args(argv)
    records, summary = collect(args.log, args.session)
    args.out.parent.mkdir(parents=True, exist_ok=True)
    with args.out.open("w", encoding="utf-8") as fh:
        for record in records:
            fh.write(json.dumps(record, ensure_ascii=False) + "\n")
    print(json.dumps(summary, ensure_ascii=False, indent=2))
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```

```python
#!/usr/bin/env python3
"""把 manifest + demand 渲染成 M0 覆盖率报告（Markdown）。"""
from __future__ import annotations

import argparse
import json
from collections import Counter
from pathlib import Path


def _pct(value) -> str:
    if value is None:
        return "N/A"
    return f"{float(value) * 100:.2f}%"


def _gate(value, threshold: float) -> str:
    if value is None:
        return "N/A"
    return "PASS" if float(value) >= threshold else "FAIL"


def render_report(
    manifest: dict,
    demand: list[dict],
    env_name: str,
    game_root: Path,
    min_coverage: float = 0.95,
    max_l1: int = 8000,
) -> str:
    stats = manifest.get("stats") or {}
    coverage = stats.get("coverage") or {}
    layers = manifest.get("layers") or {}
    l1 = layers.get("L1") or []
    l2 = layers.get("L2") or []
    l3 = layers.get("L3") or []
    l1_count = int(stats.get("l1_count") or len(l1))

    gate_rows = [
        ("L1 ≤ %d" % max_l1, _gate(l1_count, 0) if l1_count <= max_l1 else "FAIL", str(l1_count)),
        (
            "closure_refs ≥ %.2f" % min_coverage,
            _gate(coverage.get("closure_refs"), min_coverage),
            "N/A" if coverage.get("closure_refs") is None else f"{float(coverage['closure_refs']):.3f}",
        ),
        (
            "l1_sprite_disk ≥ %.2f" % min_coverage,
            _gate(coverage.get("l1_sprite_disk"), min_coverage),
            "N/A" if coverage.get("l1_sprite_disk") is None else f"{float(coverage['l1_sprite_disk']):.3f}",
        ),
        (
            "metadata == 1.0",
            "N/A" if coverage.get("metadata") is None else ("PASS" if float(coverage["metadata"]) >= 1.0 else "FAIL"),
            "N/A" if coverage.get("metadata") is None else f"{float(coverage['metadata']):.3f}",
        ),
    ]

    manifest_paths = {
        str(e.get("path", "")).casefold() for layer in (l1, l2, l3) for e in layer
    }
    demand_paths = [str(r.get("path", "")) for r in demand]
    unique_demand = sorted(set(demand_paths))
    covered = [p for p in unique_demand if p.casefold() in manifest_paths]
    missing_demand = [p for p in unique_demand if p.casefold() not in manifest_paths]
    prefix = Counter(p.split("/")[0] if "/" in p else p for p in missing_demand)

    lines = [
        f"# M0 覆盖率报告 — {env_name}",
        "",
        f"- 游戏根：`{game_root.as_posix()}`",
        f"- 生成时间：{manifest.get('generated_at', 'N/A')}",
        f"- scope：`{stats.get('scope')}`，include_core：`{stats.get('include_core')}`",
        f"- 数据来源：`{stats.get('source_mode', 'unknown')}`，优先级：`{stats.get('precedence', 'unknown')}`",
        "",
        "## 出口 gate",
        "",
        "| 指标 | 结果 | 实测 |",
        "|---|---|---|",
    ]
    lines += [f"| {name} | {result} | {value} |" for name, result, value in gate_rows]
    lines += [
        "",
        "## 层级规模",
        "",
        "| 层 | 条目数 |",
        "|---|---:|",
        f"| L1 | {len(l1)} |",
        f"| L2 | {len(l2)} |",
        f"| L3 | {len(l3)} |",
        "",
        "## 覆盖率",
        "",
        "| 指标 | 值 |",
        "|---|---:|",
        f"| L1 sprite 落盘 | {_pct(coverage.get('l1_sprite_disk'))} |",
        f"| L1 已烘焙 | {_pct(coverage.get('l1_baked'))} |",
        f"| 闭包引用解析 | {_pct(coverage.get('closure_refs'))} |",
        f"| metadata 纳入 | {_pct(coverage.get('metadata'))} |",
        f"| metadata 条目（scope） | {stats.get('metadata_entries', 0)} |",
        f"| core 条目 | {stats.get('core_entries', 0)} |",
        f"| 磁盘图片（scope） | {stats.get('disk_images', 0)} |",
        f"| 未烘焙 | {stats.get('unbaked', 0)} |",
        f"| metadata 回退命中 | {stats.get('metadata_fallback_hits', 0)} |",
        "",
        "## 闭包缺口",
        "",
    ]
    closure = stats.get("closure") or {}
    if closure:
        lines += ["| 类别 | 引用 | 解析 |", "|---|---:|---:|"]
        for name, pair in closure.items():
            total, ok = pair
            lines.append(f"| {name} | {total} | {ok} |")
        lines.append("")
    missing = stats.get("missing") or {}
    if missing:
        for kind, names in sorted(missing.items()):
            sample = ", ".join(names[:8])
            lines.append(f"- `{kind}`（{len(names)}）：{sample}")
    else:
        lines.append("- 无")
    lines += ["", "## 首屏需求覆盖", ""]
    if demand:
        lines += [
            f"- 需求记录：{len(demand)} 条，唯一路径 {len(unique_demand)} 条",
            f"- manifest 覆盖：{len(covered)} / {len(unique_demand)} = {_pct(len(covered) / len(unique_demand))}",
        ]
        if missing_demand:
            top = ", ".join(f"{k} ({v})" for k, v in prefix.most_common(8))
            lines.append(f"- 未覆盖路径前缀：{top}")
    else:
        lines.append("- 未提供 demand.jsonl")
    lines.append("")
    return "\n".join(lines)


def main(argv: list[str] | None = None) -> int:
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("--manifest", required=True, type=Path)
    parser.add_argument("--game-root", required=True, type=Path)
    parser.add_argument("--env-name", required=True)
    parser.add_argument("--out", required=True, type=Path)
    parser.add_argument("--demand", type=Path, default=None)
    parser.add_argument("--min-coverage", type=float, default=0.95)
    parser.add_argument("--max-l1", type=int, default=8000)
    args = parser.parse_args(argv)
    manifest = json.loads(args.manifest.read_text(encoding="utf-8"))
    demand = []
    if args.demand and args.demand.is_file():
        demand = [
            json.loads(line)
            for line in args.demand.read_text(encoding="utf-8").splitlines()
            if line.strip()
        ]
    text = render_report(
        manifest, demand, args.env_name, args.game_root, args.min_coverage, args.max_l1
    )
    args.out.parent.mkdir(parents=True, exist_ok=True)
    args.out.write_text(text, encoding="utf-8")
    print(text)
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```

## Rulings（计划阶段裁决，执行时入 ledger）

1. **M0 的 L2 语义**：离线无法知道“当前星系”，L2 取“全量实体池”（所有启用 variant 可达的 hull/weapon/wing sprite），运行时 M1/M2 再按星系/codex 选子集。manifest 里记录 `source_mode`，不改变 spec 的 L2 定义。
2. **覆盖率口径**：出口 gate 用 `closure_refs`（含缺失引用的严格口径）与 `l1_sprite_disk`；`metadata` 只在有 metadata 时作硬门槛，Base 的空缓存场景记 N/A。理由：Base 的 `mods/DDSCache/` 当前为空，若强行要求 baked 覆盖率，会把“开发环境未烘焙”误判为失败。
3. **Base 运行时**：按用户口径用 `jre/`（Zulu 17.0.10，`启动-高性能.bat`）。Base 的 `README-基座说明.md` 把 JDK28/Miko 写成“默认路线”，两者不一致；本计划以用户口径为准，后续若要改用 Miko 需显式改此 Ruling。
4. **core 标题资产清单**：`CORE_STATIC` 是从 C 报告 + `settings.json` 整理的**受控清单**，不是穷举；行星部分从 `planets.json` 动态取。完整性由 Base/260mods 实测的 `missing` 与后续 M3 冒烟补齐，不假装穷举。
