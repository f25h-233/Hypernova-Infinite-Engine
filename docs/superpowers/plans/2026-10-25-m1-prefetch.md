# M1 运行期预取 + 兜底 Implementation Plan（wave 模式）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 纯 mod（Form A）在 Starsector 0.98a-RC8 运行期提供「按触发点预取 + 主线程兜底加载 + JSONL 遥测」，不改变启动时间，保证进战斗/开百科/切星系时本组件预取过的纹理不缺失，且本组件单帧耗时 P99 ≤ 2 ms。

**Architecture:** 五层纯 Java 实现，全部只依赖 `starfarer.api.jar` + `json.jar` + `lwjgl.jar`（编译期）。`Config`（配置/版本探针）→ `TextureManifest`（运行时 manifest 索引）→ `TextureService`（主线程 `ensureLoaded`，先查 `oOoO` 再用 `SettingsAPI.loadTexture`）→ `PrefetchScheduler`（帧预算 + 优先级队列）→ `hooks/`（五个触发点）+ `Telemetry`（JSONL，经 `writeTextFileToCommon` 落盘）。JUnit 5 只用于纯逻辑单测（帧预算、manifest 查表、配置解析、路径归一），游戏侧行为由「实机冒烟 + 日志断言」验收。

**Spec:** `技术笔记-纹理按需加载.md`（§4.2 REQ-R1-01..11、§5.3 接口契约、§5.5 线程模型、§5.6 状态机、§6.1 不变量、§7 M1 出口）

## Global Constraints

- 编译：`javac --release 17 -encoding UTF-8`，classpath **只含** `Starsector-098-Base/starsector-core/{starfarer.api.jar,json.jar,lwjgl.jar,log4j-1.2.9.jar}`（`Global.getLogger` 的返回类型需要 log4j）；产出 class 主版本必须 61（`javap -verbose | grep "major version"`）。
- **不得** import `com.fs.graphics.*`、`com.fs.starfarer.settings.*`、`com.fs.starfarer.loading.*` 等非 api 包；**不得**使用 `java.lang.reflect.*`（INV-07）；GL 调用只允许 `org.lwjgl.opengl.GL11`（REQ-N-05/06）。
- 所有 GL 调用与 `SettingsAPI.loadTexture` 只在**主线程**执行；worker 线程只做纯 CPU。判定条件：`Thread.currentThread() == mainThread`（`mainThread` 在 `onApplicationLoad` 抓取）。非主线程调用抛 `IllegalStateException`（INV-02）。
- 不注册任何 `CampaignEventListener`/`EveryFrameCombatPlugin`/`CampaignPlugin` 时必须在 `config.enabled=false` 下整体 no-op（INV-05）。
- 游戏版本探针：`Global.getSettings().getVersionString()` 必须 **以** `"Starsector 0.98a-RC8"` 开头，否则整体 no-op 并记日志（INV-06）。
- manifest 是**唯一**预取来源：`ensureLoaded` 对不在 manifest 内的路径返回 `false` 且不加载（REQ-R1-05、§5.3 行为表）。
- 读档窗口：`Global.LOADING_SAVE == true` 期间禁止任何 GL 上传，请求入 pending 队列（INV-09）。
- 淘汰默认关闭（`eviction: false`）；M1 **不实现** `unload`/`glDeleteTextures` 的真实删除路径，只实现「拒绝并记录」的分支（REQ-R1-10 的 M1 子集）。
- 禁止 `git add -A` / `git add .`；每个 commit 只加本任务列出的文件（仓库有 8.4 GB 未跟踪 `.7z`）。
- 所有落盘 JSON/JSONL 一律 UTF-8 无 BOM；`JsonLines` 每行 ≤ 8 KB，超过则截断 `path` 字段。
- **Escape hatch：** 若断言数字/测试顺序与实现不符，按实际修正并在 `task-N-report.md` 记录偏差；**若需求自相矛盾或无法同时满足 → 停下报告，不许挑一半照做。**

## Review Focus

（spec 暗示但任何单任务测试都不覆盖的输入类别；每条对应测试落在括号里的任务）

1. **manifest 里 432 条跨层/跨 mod 重复路径** → 运行时必须「先入为主」只保留一条（层序 L1 > L2 > L3，同层按文件顺序），否则同一 path 被两个 `modId` 争用会导致 `modId` 归属漂移（Task 3）。
2. **`loadTexture` 抛 `IOException` 但文件存在**（坏图/权限）→ 必须记 `FAILED`、返回 `false`、不向调用方抛；且不重试超过 1 次（Task 4）。
3. **主线程在 `LOADING_SAVE` 窗口内调用 `ensureLoaded`** → 必须入 pending 且**不**记 `loaded`；drain 时若窗口已关闭才真正加载（Task 4 + Task 9）。
4. **`Global.getSettings()` 为 null 或 `getVersionString()` 返回 null**（极端早期/测试桩）→ 版本探针必须判 no-op 而不是 NPE（Task 2）。
5. **帧预算边界**：单次 `ensureLoaded` 本身超过 2 ms（大图/慢盘）→ 调度器必须「本次允许超预算、随后本帧不再派发」，而不是把半张图丢掉或死循环（Task 5）。

```bash
#!/usr/bin/env bash
# 用法: bash tools/java/build-mod.sh

rm -rf "$OUT/classes" "$OUT/hypernova.jar"

find "$ROOT/src/main/java" -name '*.java' > "$OUT/sources.txt"
javac --release 17 -encoding UTF-8 -cp "$CP" -d "$OUT/classes" @"$OUT/sources.txt"
# 校验主版本 61
bad=$(javap -verbose -cp "$OUT/classes" hypernova.HypernovaPlugin 2>/dev/null | grep -c "major version: 61" || true)
if [ "$bad" -ne 1 ]; then echo "FATAL: class file major version != 61" >&2; exit 1; fi
jar --create --file "$OUT/hypernova.jar" -C "$OUT/classes" .
echo "OK: $OUT/hypernova.jar"
```

```java
package hypernova.config;

public final class VersionProbe {
    public static final String EXPECTED_PREFIX = "Starsector 0.98a-RC8";

    private VersionProbe() {
    }

    public static Capability probe(String versionString, boolean frPresent) {
        if (versionString == null) {
            return new Capability(false, frPresent, "version string unavailable");
        }
        if (!versionString.startsWith(EXPECTED_PREFIX)) {
            return new Capability(false, frPresent, "game version mismatch: " + versionString);
        }
        return new Capability(true, frPresent, frPresent ? "ok" : "FR missing: vanilla path");
    }
}
```

```java
package hypernova.manifest;

import org.json.JSONArray;
import org.json.JSONObject;
import org.junit.jupiter.api.Test;
import java.util.List;
import static org.junit.jupiter.api.Assertions.*;

class TextureManifestTest {

    private static JSONObject entry(String path, String modId, int w, int h) {
        JSONObject e = new JSONObject();
        e.put("path", path);
        e.put("modId", modId);
        e.put("w", w);
        e.put("h", h);
        e.put("baked", true);
        return e;
    }

    private static JSONObject manifest(Object... layers) {
        JSONObject root = new JSONObject();
        JSONObject l = new JSONObject();
        for (int i = 0; i < layers.length; i += 2) {
            JSONArray arr = new JSONArray();
            for (Object o : (List<?>) layers[i + 1]) {
                arr.put(o);
            }
            l.put((String) layers[i], arr);
        }
        root.put("layers", l);
        return root;
    }

    @Test
    void indexesByPath() {
        JSONObject root = manifest(
                "L1", List.of(entry("graphics/ui/a.png", "core", 10, 10)),
                "L2", List.of(entry("graphics/ships/b.png", "mymod", 20, 30)),
                "L3", List.of());
        TextureManifest m = TextureManifest.fromJson(root);
        assertEquals(2, m.size());
        assertEquals("mymod", m.lookup("graphics/ships/b.png").modId());
        assertEquals(20, m.lookup("graphics/ships/b.png").w());
        assertNull(m.lookup("graphics/nope.png"));
    }

    @Test
    void earlierLayerWinsOnDuplicate() {
        JSONObject root = manifest(
                "L1", List.of(entry("graphics/weapons/x.png", "modA", 10, 10)),
                "L2", List.of(),
                "L3", List.of(entry("graphics/weapons/x.png", "core", 99, 99)));
        TextureManifest m = TextureManifest.fromJson(root);
        assertEquals(1, m.size());
        assertEquals("modA", m.lookup("graphics/weapons/x.png").modId());
        assertEquals(Layer.L1, m.lookupLayer("graphics/weapons/x.png"));
        assertEquals(1, m.discardedCount());
        assertEquals(1, m.crossLayerConflictCount());
    }

    @Test
    void skipsEntriesWithoutPath() {
        JSONObject bad = new JSONObject();
        bad.put("modId", "x");
        JSONObject root = manifest("L1", List.of(bad), "L2", List.of(), "L3", List.of());
        TextureManifest m = TextureManifest.fromJson(root);
        assertEquals(0, m.size());
    }

    @Test
    void pathsInLayerPreserveManifestOrder() {
        JSONObject root = manifest(
                "L1", List.of(entry("a.png", "m", 1, 1), entry("b.png", "m", 1, 1)),
                "L2", List.of(),
                "L3", List.of());
        TextureManifest m = TextureManifest.fromJson(root);
        assertEquals(List.of("a.png", "b.png"), m.pathsInLayer(Layer.L1));
        assertEquals(List.of(), m.pathsInLayer(Layer.L2));
    }
}
```

```java
package hypernova.manifest;

import org.json.JSONArray;
import org.json.JSONObject;

import java.util.ArrayList;
import java.util.Collections;
import java.util.EnumMap;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;

public final class TextureManifest {
    private final Map<String, TextureEntry> byPath;
    private final Map<Layer, List<String>> byLayer;
    private final int duplicates;

    private TextureManifest(Map<String, TextureEntry> byPath,
                            Map<Layer, List<String>> byLayer,
                            int duplicates) {
        this.byPath = byPath;
        this.byLayer = byLayer;
        this.duplicates = duplicates;
    }

    public static TextureManifest fromJson(JSONObject root) {
        Map<String, TextureEntry> byPath = new LinkedHashMap<>();
        Map<Layer, List<String>> byLayer = new EnumMap<>(Layer.class);
        int duplicates = 0;
        JSONObject layers = root.optJSONObject("layers");
        if (layers == null) {
            return new TextureManifest(byPath, byLayer, 0);
        }
        for (Layer layer : Layer.values()) {
            JSONArray arr = layers.optJSONArray(layer.name());
            List<String> paths = new ArrayList<>();
            byLayer.put(layer, paths);
            if (arr == null) {
                continue;
            }
            for (int i = 0; i < arr.length(); i++) {
                JSONObject e = arr.optJSONObject(i);
                if (e == null) {
                    continue;
                }
                String path = e.optString("path", "");
                if (path.isEmpty()) {
                    continue;
                }
                if (byPath.containsKey(path)) {
                    duplicates++;
                    continue;
                }
                TextureEntry entry = new TextureEntry(
                        path,
                        e.optString("modId", "unknown"),
                        e.optInt("w", 0),
                        e.optInt("h", 0),
                        e.optBoolean("baked", false),
                        layer);
                byPath.put(path, entry);
                paths.add(path);
            }
        }
        return new TextureManifest(byPath, byLayer, duplicates);
    }

    public TextureEntry lookup(String path) {
        return byPath.get(path);
    }

    public Layer lookupLayer(String path) {
        TextureEntry e = byPath.get(path);
        return e == null ? null : e.layer();
    }

    public List<String> pathsInLayer(Layer layer) {
        List<String> paths = byLayer.get(layer);
        return paths == null ? List.of() : Collections.unmodifiableList(paths);
    }

    public int size() {
        return byPath.size();
    }

    public int sizeInLayer(Layer layer) {
        List<String> paths = byLayer.get(layer);
        return paths == null ? 0 : paths.size();
    }

    public int discardedCount() {
        return duplicates;
    }
}
```

```java
package hypernova.texture;

import hypernova.manifest.TextureEntry;
import hypernova.manifest.TextureManifest;
import hypernova.telemetry.Telemetry;

import java.util.ArrayList;
import java.util.LinkedHashSet;
import java.util.List;
import java.util.Set;
import java.util.concurrent.ConcurrentHashMap;
import java.util.function.BooleanSupplier;

public final class TextureServiceImpl implements TextureService {
    private static final int MAX_RETRIES = 1;

    private final TextureManifest manifest;
    private final TextureBackend backend;
    private final Telemetry telemetry;
    private final Thread mainThread;
    private final BooleanSupplier loadingSave;
    private final Set<String> pending = new LinkedHashSet<>();
    private final ConcurrentHashMap<String, Integer> refCounts = new ConcurrentHashMap<>();

    public TextureServiceImpl(TextureManifest manifest,
                              TextureBackend backend,
                              Telemetry telemetry,
                              Thread mainThread,
                              BooleanSupplier loadingSave) {
        this.manifest = manifest;
        this.backend = backend;
        this.telemetry = telemetry;
        this.mainThread = mainThread;
        this.loadingSave = loadingSave;
    }

    @Override
    public TextureLoadResult ensureLoaded(String path) {
        if (Thread.currentThread() != mainThread) {
            String detail = "non-main-thread:" + Thread.currentThread().getName();
            telemetry.event("rejected", path, 0L, detail);
            throw new IllegalStateException("ensureLoaded must run on the display thread (" + detail + ")");
        }
        long start = System.nanoTime();
        TextureEntry entry = manifest.lookup(path);
        if (entry == null) {
            telemetry.event("miss", path, System.nanoTime() - start, "not-in-manifest");
            return new TextureLoadResult(false, false, System.nanoTime() - start, TextureState.MISS);
        }
        if (backend.isRegistered(path)) {
            refCounts.putIfAbsent(path, 1);
            telemetry.event("hit", path, System.nanoTime() - start, entry.modId());
            return new TextureLoadResult(true, false, System.nanoTime() - start, TextureState.LIVE);
        }
        if (loadingSave.getAsBoolean()) {
            pending.add(path);
            telemetry.event("queued", path, System.nanoTime() - start, "loading-save");
            return new TextureLoadResult(false, true, System.nanoTime() - start, TextureState.QUEUED);
        }
        boolean ok = loadWithRetry(path, entry);
        long nanos = System.nanoTime() - start;
        return new TextureLoadResult(ok, false, nanos, ok ? TextureState.LIVE : TextureState.FAILED);
    }

    private boolean loadWithRetry(String path, TextureEntry entry) {
        for (int attempt = 0; attempt <= MAX_RETRIES; attempt++) {
            try {
                backend.load(path);
                if (backend.isRegistered(path)) {
                    refCounts.putIfAbsent(path, 1);
                    telemetry.event("loaded", path, 0L, entry.modId());
                    return true;
                }
            } catch (Exception e) {
                telemetry.event("failed", path, 0L, e.getClass().getSimpleName() + ":" + e.getMessage());
            }
        }
        return false;
    }

    @Override
    public boolean isLoaded(String path) {
        return backend.isRegistered(path);
    }

    @Override
    public boolean acquire(String path) {
        if (manifest.lookup(path) == null) {
            return false;
        }
        refCounts.merge(path, 1, Integer::sum);
        return true;
    }

    @Override
    public void release(String path) {
        refCounts.computeIfPresent(path, (k, v) -> v > 1 ? v - 1 : 0);
    }

    @Override
    public boolean unload(String path) {
        telemetry.event("refused", path, 0L, "eviction-disabled");
        return false;
    }

    @Override
    public List<String> drainPending(int max) {
        if (loadingSave.getAsBoolean()) {
            return List.of();
        }
        List<String> out = new ArrayList<>(Math.min(max, pending.size()));
        var it = pending.iterator();
        while (it.hasNext() && out.size() < max) {
            out.add(it.next());
            it.remove();
        }
        return out;
    }

    @Override
    public int pendingCount() {
        return pending.size();
    }
}
```

```java
package hypernova.telemetry;

import org.json.JSONObject;

import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.Deque;
import java.util.List;

public final class JsonlTelemetry implements Telemetry {
    public static final String NAME = "hypernova/telemetry.jsonl";
    private static final int MAX_PATH_CHARS = 1024;

    private final TelemetrySink sink;
    private final int maxLines;
    private final boolean verbose;
    private final Deque<String> lines = new ArrayDeque<>();

    public JsonlTelemetry(TelemetrySink sink, int maxLines, boolean verbose) {
        this.sink = sink;
        this.maxLines = Math.max(1, maxLines);
        this.verbose = verbose;
    }

    @Override
    public void event(String kind, String path, long nanos, String detail) {
        if (!verbose && "hit".equals(kind)) {
            return;
        }
        JSONObject o = new JSONObject();
        o.put("t", System.currentTimeMillis());
        o.put("kind", kind);
        o.put("path", truncate(path));
        o.put("nanos", nanos);
        o.put("detail", detail == null ? "" : truncate(detail));
        synchronized (lines) {
            if (lines.size() >= maxLines) {
                int drop = maxLines / 2;
                for (int i = 0; i < drop && !lines.isEmpty(); i++) {
                    lines.pollFirst();
                }
            }
            lines.addLast(o.toString());
        }
    }
```

```java
package hypernova.scheduler;

import hypernova.manifest.Layer;
import hypernova.texture.TextureLoadResult;
import hypernova.texture.TextureService;

import java.util.ArrayDeque;
import java.util.Deque;
import java.util.EnumMap;
import java.util.Map;
import java.util.function.LongSupplier;

public final class FrameBudgetScheduler implements PrefetchScheduler {
    private final TextureService service;
    private final long budgetNanos;
    private final int perTickCap;
    private final LongSupplier clock;
    private final Map<Layer, Deque<String>> queues = new EnumMap<>(Layer.class);

    private long queued;
    private long loaded;
    private long failed;
    private long ticks;
    private long nanosLastTick;

    public FrameBudgetScheduler(TextureService service, int frameBudgetMicros, int perTickCap, LongSupplier clock) {
        this.service = service;
        this.budgetNanos = Math.max(1, frameBudgetMicros) * 1_000L;
        this.perTickCap = Math.max(1, perTickCap);
        this.clock = clock;
        for (Layer layer : Layer.values()) {
            queues.put(layer, new ArrayDeque<>());
        }
    }

    @Override
    public void enqueue(Iterable<String> paths, Layer layer) {
        Deque<String> q = queues.get(layer);
        for (String p : paths) {
            q.addLast(p);
            queued++;
        }
    }

    @Override
    public void tick() {
        long start = clock.getAsLong();
        int done = 0;
        while (done < perTickCap) {
            String next = pollNext();
            if (next == null) {
                break;
            }
            TextureLoadResult r = service.ensureLoaded(next);
            done++;
            if (r.ok() || r.queued()) {
                loaded++;
            } else {
                failed++;
            }
            if (clock.getAsLong() - start >= budgetNanos) {
                break;
            }
        }
        nanosLastTick = clock.getAsLong() - start;
        ticks++;
    }

    private String pollNext() {
        for (Layer layer : Layer.values()) {
            Deque<String> q = queues.get(layer);
            if (!q.isEmpty()) {
                return q.pollFirst();
            }
        }
        return null;
    }

    @Override
    public SchedulerStats stats() {
        return new SchedulerStats(queued, loaded, failed, ticks, nanosLastTick, backlog());
    }

    @Override
    public int backlog() {
        int n = 0;
        for (Deque<String> q : queues.values()) {
            n += q.size();
        }
        return n;
    }
}
```

```java
import java.util.function.LongSupplier;

public final class FleetDiscoveryHook {
    private final PrefetchScheduler scheduler;
    private final FleetSpriteResolver resolver;
    private final LongSupplier clockMillis;
    private final long windowMillis;
    private final Map<String, Long> seen = new HashMap<>();

    public FleetDiscoveryHook(PrefetchScheduler scheduler, FleetSpriteResolver resolver) {
        this(scheduler, resolver, System::currentTimeMillis, 300_000L);
    }

    public FleetDiscoveryHook(PrefetchScheduler scheduler, FleetSpriteResolver resolver,
                              LongSupplier clockMillis, long windowMillis) {
        this.scheduler = scheduler;
        this.resolver = resolver;
        this.clockMillis = clockMillis;
        this.windowMillis = windowMillis;
    }

    public void onFleetDetected(FleetView view) {
        long now = clockMillis.getAsLong();
        Long last = seen.get(view.name());
        if (last != null && now - last < windowMillis) {
            return;
        }
        seen.put(view.name(), now);
        List<String> paths = resolver.resolve(view);
        if (!paths.isEmpty()) {
            scheduler.enqueue(paths, Layer.L2);
        }
    }
```

```java
import hypernova.manifest.Layer;
```

```java
import java.util.ArrayList;
```

```java
public final class DeploymentHook {
    private final PrefetchScheduler scheduler;
    private final FleetSpriteResolver resolver;
    private boolean firedThisBattle;

    public DeploymentHook(PrefetchScheduler scheduler, FleetSpriteResolver resolver) {
        this.scheduler = scheduler;
        this.resolver = resolver;
    }

    public void onDeploymentScreen(FleetView playerFleet, FleetView enemyFleet) {
        if (firedThisBattle) {
            return;
        }
        firedThisBattle = true;
        List<String> paths = new ArrayList<>(resolver.resolve(playerFleet));
        for (String p : resolver.resolve(enemyFleet)) {
            if (!paths.contains(p)) {
                paths.add(p);
            }
        }
        if (!paths.isEmpty()) {
            scheduler.enqueue(paths, Layer.L1);
        }
    }

    /** 战斗结束时由装配层调用，允许下一场战斗再次触发。 */
    public void onBattleEnded() {
        firedThisBattle = false;
    }
}
```

```java
package hypernova.hooks;

import hypernova.manifest.Layer;
import hypernova.scheduler.PrefetchScheduler;

import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;
import java.util.function.LongSupplier;

public final class SystemEnterHook {
    private final PrefetchScheduler scheduler;
    private final FleetSpriteResolver resolver;
    private final LongSupplier clockMillis;
    private final long windowMillis;
    private final Map<String, Long> lastEntered = new HashMap<>();

    public SystemEnterHook(PrefetchScheduler scheduler, FleetSpriteResolver resolver) {
        this(scheduler, resolver, System::currentTimeMillis, 60_000L);
    }

    public SystemEnterHook(PrefetchScheduler scheduler, FleetSpriteResolver resolver,
                           LongSupplier clockMillis, long windowMillis) {
        this.scheduler = scheduler;
        this.resolver = resolver;
        this.clockMillis = clockMillis;
        this.windowMillis = windowMillis;
    }

    public void onSystemEntered(String systemId, List<FleetView> fleets) {
        long now = clockMillis.getAsLong();
        Long last = lastEntered.get(systemId);
        if (last != null && now - last < windowMillis) {
            return;
        }
        lastEntered.put(systemId, now);
        List<String> paths = new ArrayList<>();
        for (FleetView f : fleets) {
            for (String p : resolver.resolve(f)) {
                if (!paths.contains(p)) {
                    paths.add(p);
                }
            }
        }
        if (!paths.isEmpty()) {
            scheduler.enqueue(paths, Layer.L2);
        }
    }
}
```

```java
package hypernova.hooks;

import hypernova.texture.TextureService;

import java.util.List;
import java.util.function.BooleanSupplier;

public final class SaveLoadGuard {
    private static final int MAX_PER_TICK = 32;

    private final BooleanSupplier loadingSave;
    private final TextureService service;

    public SaveLoadGuard(BooleanSupplier loadingSave, TextureService service) {
        this.loadingSave = loadingSave;
        this.service = service;
    }

    public int tick() {
        if (loadingSave.getAsBoolean()) {
            return 0;
        }
        List<String> drained = service.drainPending(MAX_PER_TICK);
        int loaded = 0;
        for (String path : drained) {
            if (service.ensureLoaded(path).ok()) {
                loaded++;
            }
        }
        return loaded;
    }
}
```

```java
package hypernova.adapter;
```

```java
import com.fs.starfarer.api.campaign.CampaignFleetAPI;
import hypernova.hooks.ContactDialogHook;
```

```java
import hypernova.hooks.FleetDiscoveryHook;
import hypernova.hooks.FleetView;
import hypernova.hooks.SystemEnterHook;

import java.util.ArrayList;
import java.util.HashSet;
import java.util.List;
import java.util.Set;

public final class TriggerPoller {

    public interface World {
        String currentLocationName();

        String combatsKey();

        boolean codexOpen();

        boolean contactDialogOpen();

        List<CampaignFleetAPI> fleetsInLocation();

        List<CampaignFleetAPI> playerVisibleFleets();

        boolean inCombat();

        List<String> deployedVariantIds();
    }

    private final World world;
    private final FleetViewFactory factory;
    private final FleetDiscoveryHook discoveryHook;
    private final ContactDialogHook contactHook;
    private final SystemEnterHook systemHook;
    private final DeploymentHook deploymentHook;

    private String lastLocation;
    private String lastCombatsKey = "";
    private boolean lastCodex;
    private boolean lastInCombat;
    private final Set<String> seenVisibleFleetNames = new HashSet<>();

    public TriggerPoller(World world,
                         FleetViewFactory factory,
                         FleetDiscoveryHook discoveryHook,
                         ContactDialogHook contactHook,
                         SystemEnterHook systemHook,
                         DeploymentHook deploymentHook) {
        this.world = world;
        this.factory = factory;
        this.discoveryHook = discoveryHook;
        this.contactHook = contactHook;
        this.systemHook = systemHook;
        this.deploymentHook = deploymentHook;
    }

    public void tick() {
        try {
            tickLocation();
            tickCombat();
            tickCodex();
            tickVisibleFleets();
        } catch (Throwable ignored) {
            // 触发点异常绝不打断游戏（INV-05 的失败方向：静默降级）
        }
    }

    private void tickLocation() {
        String location = world.currentLocationName();
        if (location == null || location.equals(lastLocation)) {
            return;
        }
        lastLocation = location;
        systemHook.onSystemEntered(location, views(world.fleetsInLocation()));
    }

    private void tickCombat() {
        boolean combat = world.inCombat();
        boolean rising = combat && !lastInCombat;
        lastInCombat = combat;
        if (!rising) {
            return;
        }
        deploymentHook.onDeploymentScreen(
                factory.build("combat", world.deployedVariantIds()),
                factory.build("enemy", List.of()));
    }

    private void tickCodex() {
        boolean open = world.codexOpen();
        boolean rising = open && !lastCodex;
        lastCodex = open;
        if (!rising) {
            return;
        }
        for (FleetView view : views(world.fleetsInLocation())) {
            contactHook.onDialogShown(view);
        }
    }

    private void tickVisibleFleets() {
        for (CampaignFleetAPI fleet : world.playerVisibleFleets()) {
            String name = fleet.getName();
            if (name != null && seenVisibleFleetNames.add(name)) {
                discoveryHook.onFleetDetected(factory.toView(fleet));
            }
        }
    }

    private List<FleetView> views(List<CampaignFleetAPI> fleets) {
        List<FleetView> out = new ArrayList<>(fleets.size());
        for (CampaignFleetAPI fleet : fleets) {
            out.add(factory.toView(fleet));
        }
        return out;
    }
}
```

```java
    }

        LocationAPI loc = Global.getSector() == null ? null : Global.getSector().getCurrentLocation();
        return loc == null ? List.of() : loc.getFleets();
    }

    @Override
    public List<CampaignFleetAPI> playerVisibleFleets() {
        List<CampaignFleetAPI> out = new ArrayList<>();
        if (Global.getSector() == null) {
            return out;
        }
        CampaignFleetAPI player = Global.getSector().getPlayerFleet();
        LocationAPI loc = Global.getSector().getCurrentLocation();
        if (player == null || loc == null) {
            return out;
        }
        for (CampaignFleetAPI fleet : loc.getFleets()) {
            if (fleet != player && fleet.isVisibleToPlayerFleet()) {
                out.add(fleet);
            }
        }
        return out;
    }

    @Override
    public boolean inCombat() {
        return Global.getCombatEngine() != null;
    }

    @Override
    public List<String> deployedVariantIds() {
        List<String> ids = new ArrayList<>();
        CombatEngineAPI engine = Global.getCombatEngine();
        if (engine == null) {
            return ids;
        }
        for (int side = 0; side <= 1; side++) {
            CombatFleetManagerAPI manager = engine.getFleetManager(side);
            if (manager == null) {
                continue;
            }
            for (FleetMemberAPI m : manager.getDeployedCopy()) {
                if (m.getVariant() != null) {
                    ids.add(m.getVariant().getHullVariantId());
                }
            }
            for (FleetMemberAPI m : manager.getReservesCopy()) {
                if (m.getVariant() != null) {
                    ids.add(m.getVariant().getHullVariantId());
                }
            }
        }
        return ids;
    }
```

```python
"""M1 冒烟检查：读 starsector.log 与 telemetry.jsonl，输出 PASS/FAIL。

from __future__ import annotations

import json

from pathlib import Path

BANNER = "正在运行 Starsector"
ANCHOR = "Parsing entry"
OWN_THREAD = "main"


def sessions(lines: list[str]) -> list[int]:
    return [i for i, line in enumerate(lines) if BANNER in line]


def main() -> int:
    ap = argparse.ArgumentParser()
    ap.add_argument("--game", required=True)
    args = ap.parse_args()
    core = Path(args.game) / "starsector-core"
    log = core / "starsector.log"
    telemetry = Path(args.game) / "saves" / "common" / "hypernova" / "telemetry.jsonl"
    checks: list[tuple[str, bool, str]] = []

    lines = text.splitlines()
    starts = sessions(lines)
    last_start = starts[-1] if starts else 0
    session = lines[last_start:]

    active = any("Hypernova active:" in l for l in session)
    checks.append(("plugin active in last session", active, "log line 'Hypernova active:'"))

    disabled = any("Hypernova disabled:" in l for l in session)
    checks.append(("no disable reason", not disabled, "log line 'Hypernova disabled:'"))

    if telemetry.is_file():
        events = []
        for line in telemetry.read_text(encoding="utf-8", errors="replace").splitlines():
            line = line.strip()
            if not line:
                continue
            try:
                events.append(json.loads(line))
            except json.JSONDecodeError:
                checks.append(("telemetry lines are valid JSON", False, line[:80]))
                break
        kinds = [e.get("kind") for e in events]
        checks.append(("telemetry has loaded events", "loaded" in kinds, f"kinds={sorted(set(kinds))}"))
        checks.append(("no non-main-thread rejection",
                       "rejected" not in kinds,
                       f"rejected={kinds.count('rejected')}"))
        failed = [e for e in events if e.get("kind") == "failed"]
        checks.append(("failed rate <= 5%",
                       len(failed) <= max(1, len(events) // 20),
                       f"failed={len(failed)} total={len(events)}"))
    else:
        checks.append(("telemetry file exists", False, str(telemetry)))

    width = max(len(name) for name, _, _ in checks)
    ok = True
    for name, passed, detail in checks:
        ok = ok and passed
        print(f"{'PASS' if passed else 'FAIL'}  {name:<{width}}  {detail}")
    return 0 if ok else 1


if __name__ == "__main__":
    sys.exit(main())
```

## Rulings（计划阶段裁决，执行时入 ledger）

1. **M1 不实现真正的 `unload`**：spec 的 REQ-R1-10 要求淘汰清 `oOoO`/`TextureLoader` 缓存 + `glDeleteTextures`，但 §5.7 明确「无全局 Sprite 注册表，无法证明无人引用」，且默认 `eviction=false`。M1 只交付「拒绝并记录」分支，真正的删除路径留到 M2/M3（届时需要先做 id 生命周期实测）。**理由**：M1 的出口只要求 REQ-R1-10 的默认关闭行为；实现删除路径但没有验证手段会把风险前置。
2. **触发点③用轮询而非 `BattleCreationPlugin`**：`BattleCreationPlugin.pickBattleCreationPlugin` 在 `starfarer_obf.jar` 里只有 `ModAndPluginData` 的 pick 端，没有找到消费端，无法验证调用时机。改用 `TriggerPoller` 在 `HypernovaCombatPlugin.advance` 里检测 `inCombat()` 上升沿 + `deployedVariantIds()`。**代价**：部署界面与首帧之间有一个 tick 的延迟（≤ 1 帧）；若冒烟显示部署界面仍有缺失，M2 再找 `BattleCreationPlugin` 的消费端。
3. **触发点①/②/④ 全部走轮询边沿**，不依赖 `DiscoverEntityListener`/`DetectedEntityListener`/`CurrentLocationChangedListener` 的派发时机（这三者的实际调用点未在反编译源码中全量确认）。`HypernovaCampaignListener` 只保留两个**已验证**的回调：`CoreUITabListener.reportAboutToOpenCoreTab`（②的加速路径）与 `BaseFleetEventListener.reportBattleFinished`（③的复位）。**代价**：轮询每帧读 `LocationAPI.getFleets()`，在 260mods 大星系可能有开销——M1 只在 Base 验收，260mods 的性能另测。
4. **manifest 运行时不含 `absolutePath/ddsPath`**：M1 走 `SettingsAPI.loadTexture(path)` 的引擎 key，不需要绝对路径；裁剪后 Base manifest 约 1.4 MB → 预计 < 400 KB，JSON 解析在主线程 `onApplicationLoad` 一次完成（< 100 ms），可接受。260mods 的 39 MB 需要另测，M1 验收只在 Base 做。
5. **JUnit 用 console-standalone jar 手工放 `lib/`**：仓库无 Gradle/Maven，`lib/` 入 `.gitignore`；`run-tests.sh` 缺失 jar 时 exit 2 并给出下载 URL。
6. **无 FR 的降级（REQ-R1-11）在 M1 只记录能力不切换路径**：`TextureServiceImpl` 走 `SettingsAPI.loadTexture`，在 FR 与无 FR 下都是同一个引擎入口；差异只在 DDS 命中（FR 内部），M1 不依赖。因此 `frAvailable` 只用于日志与 telemetry 标注。
