# M2.6 DDS 按需物化 + 有界 LRU Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 M2.5 的跳过/代理/按需物化之上，先补齐生命周期门禁（I2/I3/m4/w4 + skip generation），再把按需物化升级为 BC7 DDS + 可选有界 LRU，并用真实进程 selftest 与自动化菜单 A/B 取证；战斗/读档/手动目检留给用户回到机器前。

**Architecture:** `LazySkipIndex` v2 sidecar 把 `absPath`/`ddsPath` 带到运行期；首次 bind 先走 `DDSIntegration.getTexture/commitTexture` + `newVanillaTextureHandler`（BC7，target 36492），任一预校验失败回退 M2.5 PNG；LRU 只在主线程、场景切换/预算触发时，按估算字节淘汰本组件物化且满足 grace/基础集排除的代理，经 FR bridge `glDeleteTextures` 删除并把代理复位到共享 1×1 透明占位；所有新能力默认 off。

**Tech Stack:** Java 17（major 61）、ASM 9.1（agent 已内置）、Python 3.14 stdlib（`python -I`）、pytest 9、JUnit 5、`tools/smoke_run.py`、Git Bash（Windows 11）。

**Spec:** `技术笔记-纹理按需加载.md` §5.7（所有权与淘汰）、§6.1（INV-08/10）、§7 M2.6、REQ-R1-10、REQ-R2-01..04；方向 `大饼-DDS按需物化与LRU.md`；M2.5 结果 `docs/m25-results.md`；M2.5 final-review §5（M2.6 gates）。

## Global Constraints

- **宿主锁**：Starsector **0.98a-RC8** + Fast Rendering **0.9.7rc2**。DDS/GL 反射入口必须先过 shape gate；任一方法/字段缺失 → DDS/淘汰单独降级，**不阻止启动、不关闭 M2.5 PNG 懒加载**。FR 版本门已由 `HypernovaAgent` 的 `FileIndexHook.supportedFrVersion()` 提供，不改。
- **默认 off**：`textures.lazy.enabled=false`、`textures.lazy.eviction.enabled=false`。M2.6 验收只通过 `-Dhypernova.textures.lazy=true`（以及 `...dds=true` / `...eviction=true` / `...selftest=true`）开启；**不得改默认值**。回滚 = 配置/属性 false 或删 agent 行。
- **agent 顺序**：Hypernova agent 必须在 FR **之前**（`tools/install_agent.py` 已保证）；不修改 FR/vanilla 类，不新增 transformer（复用 M2.5 的 queue/register/drain/thread 四个 hook）。
- **线程红线**：任何 GL/`oOoO`/`TextureLoader` 提交只在加载线程（`FileLoader.mainThread`）或游戏主线程；**淘汰只在游戏主线程**。worker 只做纯 CPU。
- **DDS 预校验**：`DDS ` magic + DX10 头 + `dxgiFormat=98`（BC7）+ 尺寸等于 manifest + 文件长度 ≥ 148 + ceil(w/4)×ceil(h/4)×16。任一失败 → PNG 回退并计数；**绝不依赖 render 线程回退**（FR 的坏 DDS 会 `AsyncException` + `isStateCorrupted=true`，不可恢复）。
- **generation 门禁**：运行时 skip 文件头 `# generation=<sha256>` 必须等于同目录 `manifest-v1.json` 的 sha256。缺失/不符 → `lazy disabled`（全部走原版加载），**不允许跳过 L1**。
- **INV-10**：代理声明尺寸必须等于真图/`TextureData.imageWidth/imageHeight`。不一致 → 计数 `dimMismatch`、置 `disabled=1`、写 ERROR；不静默。
- **不变游戏配置**：不动 `enabled_mods.json`、`Miko_*.txt`、`fr.vmparams`、游戏设置；安装只走 `tools/install_manifest.py` / `tools/install_agent.py` / `tools/java/install-manifest.sh`。**绝不用 `taskkill //F //IM node.exe`**。
- **日志纪律**：只分析最后一个 `hypernova agent premain` 之后的会话；错误计数只取最后一个 `Fast Rendering: v0.9.` 锚点之后。
- **Java/Python**：`--release 17`、`-encoding UTF-8`、class major 61；agent 不新增依赖（ASM 9.1 已内置），agent 源码不得 import 游戏/FR 类（一律反射/ASM 字符串）。Python 只用 stdlib，必须能在 `python -I` 下运行。
- **Escape hatch**：若计划里的断言数字/测试顺序与实现不符，按实际修正并在报告里说明，无需请示。**若需求自相矛盾或无法同时满足 → 停下报告，不许挑一半照做。**
- **远程桌面范围**：本计划只做 Task 0 门禁 + DDS/LRU 实现 + 自动化菜单 A/B + 真实进程 selftest。**战斗/读档/分辨率/手动目检明确 deferred**；不得在结果里写“战斗/长会话净收益通过”。

## Review Focus

1. **坏 DDS 是灾难路径**：任何缺失/非 BC7/尺寸不符/截断必须在我们提交前被 `DdsCheck` 拦住并回退 PNG；render 线程的 `AsyncException` 不可恢复。测试：`DdsCheckTest` 覆盖 magic/DX10/dxgi/尺寸/短文件；`DdsBridgeTest` 覆盖 null/非 DDS。
2. **FR 形状漂移**：`DDSIntegration.getTexture/commitTexture`、`TextureData` 字段、`TextureLoader.newVanillaTextureHandler`、bridge `glDeleteTextures` 任一缺失 → 该能力降级并记录，**不能**让 `LazyTextures` 崩或关闭 M2.5 PNG。测试：`DdsBridgeTest` + `GlBridgeTest`（无 FR 时 available=false）。
3. **过期的 manifest/skip**：generation 不符时必须 `lazy disabled`，而不是继续跳过；否则可能把新 L1 永久跳过。测试：`LazyGateTest.generationCheckMatchesManifestHash`。
4. **drain 后新增 PENDING**：drain 完成后不得留下不在 `oOoO.new` 的代理（Shadowverse/VideoLib 直接读 map 会 `IllegalArgumentException`）。实现用 `drained` 门禁 + `DRAIN_LOCK`；测试 `skipAllowed(..., drained=true, ...)==false`，并在报告中说明线程合法时立即注册、否则 fail-open。
5. **LRU 的 id 卫生**：删除必须走 FR bridge（同步 `TextureManager` 状态），代理先复位到**合法 1×1 占位 id**，不能留已删 id/-1/0 悬空；re-materialize 必须重新 `glGenTextures`。测试：`LazyEvictionTest`（选择规则）+ selftest（真实 GL id 删除/重建）。
6. **线程越界**：eviction/placeholder/`glDeleteTextures` 只能主线程；DDS commit 只能主/加载线程。selftest 只能淘汰不可见路径（排除 `graphics/ui/`、`graphics/fonts/`、`graphics/intro/`）。
7. **口径**：菜单 A/B 只回答“菜单时间无回归 + 计数/正确性”；不得把菜单时刻收益写成启动/战斗/长会话收益；LRU 的 A→B/战斗收益 deferred。

```java
        assertFalse(LazyTextures.dimensionsMatch(64, 16, 32, 16));
        assertFalse(LazyTextures.dimensionsMatch(32, 32, 32, 16));

        assertTrue(LazyTextures.skipAllowed(true, false, false, false,
                indexWith("graphics/a.png"), "TEXTURE", "graphics/a.png"));
        assertFalse(LazyTextures.skipAllowed(true, false, false, true,
                indexWith("graphics/a.png"), "TEXTURE", "graphics/a.png"));
        assertFalse(LazyTextures.skipAllowed(false, false, false, false,
                indexWith("graphics/a.png"), "TEXTURE", "graphics/a.png"));
        assertFalse(LazyTextures.skipAllowed(true, true, false, false,
                indexWith("graphics/a.png"), "TEXTURE", "graphics/a.png"));
    }

    @Test
    void generationCheckMatchesManifestHash(@TempDir Path dir) throws Exception {
        Path manifest = dir.resolve("manifest-v1.json");
        Files.writeString(manifest, "{\"layers\":{}}");
        String sha = LazyTextures.sha256(manifest);
        Path skip = dir.resolve("lazy-skip-v1.txt");
        Files.writeString(skip, "# generation=" + sha + "\ngraphics/a.png\t1\t1\n");

        Files.writeString(skip, "# generation=deadbeef\ngraphics/a.png\t1\t1\n");
```

```java
package hypernova.agent.textures;

import java.io.BufferedReader;
import java.nio.charset.StandardCharsets;
import java.nio.file.Files;
import java.nio.file.Path;
import java.util.HashMap;
import java.util.Map;

/** Immutable path -> (w,h) index generated from the runtime manifest. */
public final class LazySkipIndex {
    public record Dim(int w, int h) {
    }

    private final Map<String, Dim> byPath;
    private final int invalid;
    private final long loadMillis;
    private final String generation;

    private LazySkipIndex(Map<String, Dim> byPath, int invalid, long loadMillis,
                          String generation) {
        this.byPath = byPath;
        this.invalid = invalid;
        this.loadMillis = loadMillis;
        this.generation = generation;
    }

    public static LazySkipIndex load(Path file) throws Exception {
        long t0 = System.nanoTime();
        Map<String, Dim> map = new HashMap<>(1 << 17);
        int invalid = 0;
        String generation = null;
        try (BufferedReader reader = Files.newBufferedReader(file, StandardCharsets.UTF_8)) {
            String line;
            while ((line = reader.readLine()) != null) {
                if (line.isEmpty()) continue;
                if (line.charAt(0) == '#') {
                    if (line.startsWith("# generation=")) {
                        generation = line.substring("# generation=".length()).trim();
                    }
                    continue;
                }
                int t1 = line.indexOf('\t');
                int t2 = t1 < 0 ? -1 : line.indexOf('\t', t1 + 1);
                if (t1 <= 0 || t2 <= t1) {
                    invalid++;
                    continue;
                }
                try {
                    int w = Integer.parseInt(line.substring(t1 + 1, t2));
                    int h = Integer.parseInt(line.substring(t2 + 1));
                    if (w <= 0 || h <= 0) {
                        invalid++;
                        continue;
                    }
                    map.put(line.substring(0, t1), new Dim(w, h));
                } catch (NumberFormatException e) {
                    invalid++;
                }
            }
        }
        long ms = (System.nanoTime() - t0) / 1_000_000L;
        return new LazySkipIndex(map, invalid, ms, generation);
    }

    public boolean contains(String path) {
        return path != null && byPath.containsKey(path);
    }

    public Dim get(String path) {
        return byPath.get(path);
    }

    public int size() {
        return byPath.size();
    }

    public int invalid() {
        return invalid;
    }

    public long loadMillis() {
        return loadMillis;
    }

    public String generation() {
        return generation;
    }
}
```

```python
    layers = manifest.get("layers") or {}
    if not isinstance(layers, dict):
        layers = {}
    l1 = {e.get("path") for e in layers.get("L1") or [] if isinstance(e, dict)}
    stats = {
        "l1": len(l1), "candidates": 0, "skip": 0, "dds": 0,
        "excluded_l1": 0, "excluded_invalid": 0,
        "excluded_blacklist": 0, "excluded_duplicate": 0,
    }
    seen: set[str] = set()
    out: list[tuple[str, int, int, str, str, bool]] = []
    for layer in ("L2", "L3"):
        for entry in layers.get(layer) or []:
            if not isinstance(entry, dict):
                continue
            stats["candidates"] += 1
            path = entry.get("path")
            if not isinstance(path, str) or not path:
                stats["excluded_invalid"] += 1
                continue
            if path in l1:
                stats["excluded_l1"] += 1
                continue
            if path.startswith(BLACKLIST_PREFIX):
                stats["excluded_blacklist"] += 1
                continue
            w, h = entry.get("w"), entry.get("h")
            if not isinstance(w, int) or not isinstance(h, int) or w <= 0 or h <= 0:
                stats["excluded_invalid"] += 1
                continue
            if path in seen:
                stats["excluded_duplicate"] += 1
                continue
            seen.add(path)
            abs_path = entry.get("absolutePath")
            dds_path = entry.get("ddsPath")
            abs_path = abs_path if isinstance(abs_path, str) else ""
            dds_path = dds_path if isinstance(dds_path, str) else ""
            baked = bool(entry.get("baked")) and bool(dds_path)
            if baked:
                stats["dds"] += 1
            out.append((path, w, h, abs_path, dds_path, baked))
    out.sort()
    stats["skip"] = len(out)
    return out, stats


def write_skip_v2(path: Path, rows: list[tuple[str, int, int, str, str, bool]],
                  header: str | None = None) -> None:
    path.parent.mkdir(parents=True, exist_ok=True)
    with path.open("w", encoding="utf-8", newline="\n") as f:
        if header is not None:
            f.write(header.rstrip("\n") + "\n")
        for p, w, h, abs_path, dds_path, baked in rows:
            f.write(f"{p}\t{w}\t{h}\t{abs_path}\t{dds_path}\t{1 if baked else 0}\n")
        f.flush()
        os.fsync(f.fileno())
```

```java
package hypernova.agent.textures;

import java.io.BufferedReader;
import java.nio.charset.StandardCharsets;
import java.nio.file.Files;
import java.nio.file.Path;
import java.util.HashMap;
import java.util.Map;

/**
 * Immutable path -> (w,h[,absPath,ddsPath,baked]) index.
 *
 * <p>v1: 3 tab-separated columns. v2: 6 columns
 * (path, w, h, absPath, ddsPath, baked). The optional generation header
 * "# generation=<sha256>" is the runtime manifest hash (Task 0 checks it).
 */
public final class LazySkipIndex {
    public record Entry(int w, int h, String absPath, String ddsPath, boolean baked) {
        public boolean hasDds() {
            return ddsPath != null && !ddsPath.isBlank();
        }
    }

    private final Map<String, Entry> byPath;
    private final int invalid;
    private final long loadMillis;
    private final String generation;

    private LazySkipIndex(Map<String, Entry> byPath, int invalid, long loadMillis,
                          String generation) {
        this.byPath = byPath;
        this.invalid = invalid;
        this.loadMillis = loadMillis;
        this.generation = generation;
    }

    public static LazySkipIndex load(Path file) throws Exception {
        long t0 = System.nanoTime();
        Map<String, Entry> map = new HashMap<>(1 << 17);
        int invalid = 0;
        String generation = null;
        try (BufferedReader reader = Files.newBufferedReader(file, StandardCharsets.UTF_8)) {
            String line;
            while ((line = reader.readLine()) != null) {
                if (line.isEmpty()) continue;
                if (line.charAt(0) == '#') {
                    if (line.startsWith("# generation=")) {
                        generation = line.substring("# generation=".length()).trim();
                    }
                    continue;
                }
                String[] parts = line.split("\t", -1);
                if (parts.length < 3 || parts[0].isEmpty()) {
                    invalid++;
                    continue;
                }
                try {
                    int w = Integer.parseInt(parts[1]);
                    int h = Integer.parseInt(parts[2]);
                    if (w <= 0 || h <= 0) {
                        invalid++;
                        continue;
                    }
                    String abs = parts.length >= 4 && !parts[3].isEmpty() ? parts[3] : null;
                    String dds = parts.length >= 5 && !parts[4].isEmpty() ? parts[4] : null;
                    boolean baked = parts.length >= 6
                            && ("1".equals(parts[5]) || "true".equalsIgnoreCase(parts[5]));
                    map.put(parts[0], new Entry(w, h, abs, dds, baked));
                } catch (NumberFormatException e) {
                    invalid++;
                }
            }
        }
        long ms = (System.nanoTime() - t0) / 1_000_000L;
        return new LazySkipIndex(map, invalid, ms, generation);
    }

    public boolean contains(String path) {
        return path != null && byPath.containsKey(path);
    }

    public Entry get(String path) {
        return byPath.get(path);
    }

    public int size() {
        return byPath.size();
    }

    public int invalid() {
        return invalid;
    }

    public long loadMillis() {
        return loadMillis;
    }

    public String generation() {
        return generation;
    }
}
```

```java
package hypernova.agent.textures;

import java.io.IOException;
import java.io.InputStream;
import java.nio.charset.StandardCharsets;
import java.nio.file.Files;
import java.nio.file.Path;

/**
 * Pure pre-validation for VOpt BC7 DDS files. FR's DDS path reads the whole
 * file and uploads it on the render thread; a bad file becomes an unrecoverable
 * AsyncException/isStateCorrupted. Every check here must pass before
 * DDSIntegration.commitTexture is called.
 */
public final class DdsCheck {
    static final int HEADER_BYTES = 148;
    static final int DXGI_FORMAT_BC7 = 98;

    public record Result(boolean ok, String reason, int width, int height, int dxgi) {
    }

    private DdsCheck() {
    }

    public static Result check(Path file, int expectedWidth, int expectedHeight) {
        if (file == null) return new Result(false, "no dds path", 0, 0, 0);
        if (!Files.isRegularFile(file)) return new Result(false, "missing", 0, 0, 0);
        final long size;
        final byte[] b = new byte[HEADER_BYTES];
        try {
            size = Files.size(file);
            try (InputStream in = Files.newInputStream(file)) {
                int n = in.readNBytes(b, 0, HEADER_BYTES);
                if (n < HEADER_BYTES) {
                    return new Result(false, "short header " + n, 0, 0, 0);
                }
            }
        } catch (IOException e) {
            return new Result(false, "read failed: " + e, 0, 0, 0);
        }
        if (b[0] != 'D' || b[1] != 'D' || b[2] != 'S' || b[3] != ' ') {
            return new Result(false, "bad magic", 0, 0, 0);
        }
        int headerSize = le32(b, 4);
        if (headerSize != 124) {
            return new Result(false, "bad header size " + headerSize, 0, 0, 0);
        }
        int height = le32(b, 12);
        int width = le32(b, 16);
        if (!"DX10".equals(new String(b, 84, 4, StandardCharsets.US_ASCII))) {
            return new Result(false, "not DX10", width, height, 0);
        }
        int dxgi = le32(b, 128);
        if (dxgi != DXGI_FORMAT_BC7) {
            return new Result(false, "dxgi " + dxgi, width, height, dxgi);
        }
        if (width <= 0 || height <= 0) {
            return new Result(false, "bad dims " + width + "x" + height, width, height, dxgi);
        }
        if (width != expectedWidth || height != expectedHeight) {
            return new Result(false, "dims " + width + "x" + height
                    + " != " + expectedWidth + "x" + expectedHeight, width, height, dxgi);
        }
        long blocks = ((width + 3L) / 4L) * ((height + 3L) / 4L);
        long minBytes = HEADER_BYTES + blocks * 16L;
        if (size < minBytes) {
            return new Result(false, "short dds data " + size + " < " + minBytes,
                    width, height, dxgi);
        }
        return new Result(true, "ok", width, height, dxgi);
    }

    private static int le32(byte[] b, int o) {
        return (b[o] & 0xff) | ((b[o + 1] & 0xff) << 8)
                | ((b[o + 2] & 0xff) << 16) | ((b[o + 3] & 0xff) << 24);
    }
}
```

```java
package hypernova.agent.textures;

import hypernova.agent.AgentLog;

import java.lang.reflect.Field;
import java.lang.reflect.Method;
import java.nio.file.Path;
import java.util.concurrent.atomic.AtomicBoolean;

/**
 * Reflection bridge to FR 0.9.7rc2 DDSIntegration/TextureData and the merged
 * TextureLoader.newVanillaTextureHandler. Any shape mismatch disables only the
 * DDS path; the caller falls back to the M2.5 PNG materializer.
 */
public final class DdsBridge {
    public record Data(Object texData, int imageWidth, int imageHeight,
                       int width, int height, Path ddsPath) {
    }

    private static volatile boolean resolved;
    private static volatile boolean available;
    private static volatile Method getTexture;
    private static volatile Method commitTexture;
    private static volatile Method isDds;
    private static volatile Field imageWidth;
    private static volatile Field imageHeight;
    private static volatile Field width;
    private static volatile Field height;
    private static volatile Field ddsPath;
    private static final AtomicBoolean FAIL_LOGGED = new AtomicBoolean();

    private DdsBridge() {
    }

    public static boolean available() {
        resolve();
        return available;
    }

    public static Data get(Path absoluteImagePath) {
        resolve();
        if (!available) return null;
        try {
            Object data = getTexture.invoke(null, absoluteImagePath);
            if (data == null) return null;
            if (isDds != null && !(Boolean) isDds.invoke(data)) return null;
            Path file = (Path) ddsPath.get(data);
            if (file == null) return null;
            return new Data(data, imageWidth.getInt(data), imageHeight.getInt(data),
                    width.getInt(data), height.getInt(data), file);
        } catch (Throwable t) {
            fail("getTexture failed for " + absoluteImagePath, t);
            return null;
        }
    }

    public static int commit(Object textureData) {
        resolve();
        if (!available) return -1;
        try {
            return (int) commitTexture.invoke(null, textureData);
        } catch (Throwable t) {
            fail("commitTexture failed", t);
            return -1;
        }
    }

    /**

                return m.invoke(null, null, path, textureData, id);
            }

        throw new NoSuchMethodException("TextureLoader.newVanillaTextureHandler"
                + "(String,String,TextureData,int)");
```

```java
    static List<ProxyEntry> selectVictims(List<ProxyEntry> ready, long liveBytes,
                                          long budgetBytes, long graceNanos,
                                          long now, int max) {
        if (liveBytes <= budgetBytes) return List.of();
        long low = budgetBytes - (budgetBytes / 5); // 80%
        List<ProxyEntry> candidates = new ArrayList<>();
        for (ProxyEntry e : ready) {
            if (e == null || !e.ready || e.bytes <= 0 || e.glId <= 0) continue;
            if (e.startup || isBasicPath(e.path)) continue;
            if (e.lastUseNanos == 0 || now - e.lastUseNanos < graceNanos) continue;
            candidates.add(e);
        }
        candidates.sort(Comparator.comparingLong(e -> e.lastUseNanos));
        List<ProxyEntry> out = new ArrayList<>();
        long live = liveBytes;
        for (ProxyEntry e : candidates) {
            if (live <= low || out.size() >= max) break;
            out.add(e);
            live -= e.bytes;
        }
        return out;
    }

    static boolean isBasicPath(String path) {
        if (path == null) return true;
        return path.startsWith("graphics/ui/")
                || path.startsWith("graphics/fonts/")
                || path.startsWith("graphics/intro/");
    }

    static boolean shouldDeleteOldId(boolean owned, int oldId, int newId,
                                     int placeholder, boolean allowedThread) {
        return owned && allowedThread && oldId > 0 && oldId != newId
                && oldId != placeholder;
    }

    private static long budgetBytes() {
        return evictionBudgetMb <= 0 ? Long.MAX_VALUE : evictionBudgetMb * 1024L * 1024L;
    }

    private static void evictPass() {
        if (!eviction || disabled || Thread.currentThread() != runtimeMain) return;
        long live = LIVE_BYTES.get();
        long budget = budgetBytes();
        if (live <= budget) return;
        List<ProxyEntry> ready = new ArrayList<>();
        for (ProxyEntry e : PROXIES.values()) {
            if (e.ready) ready.add(e);
        }
        List<ProxyEntry> victims = selectVictims(ready, live, budget,
                evictionGraceNanos, System.nanoTime(), evictionMaxPerPass);
        int n = 0;
        long bytes = 0;
        for (ProxyEntry e : victims) {
            long b = e.bytes;
            if (evictOne(e, false)) {
                n++;
                bytes += b;
            }
        }
        EVICT_PASSES.incrementAndGet();
        if (n > 0) {
            AgentLog.info("lazy: eviction pass evicted=" + n + " bytes=" + bytes
                    + " live=" + LIVE_BYTES.get() + " budget=" + budget);
        }
    }

    private static boolean evictOne(ProxyEntry e, boolean force) {
        if (e == null || !e.ready || e.glId <= 0 || e.obj == null) return false;
        if (!force && (e.startup || isBasicPath(e.path))) return false;
        if (Thread.currentThread() != runtimeMain) return false;
        if (!ensurePlaceholder()) return false;
        int id;
        synchronized (e) {
            if (!e.ready || e.glId <= 0) return false;
            ProxyShape shape = proxyShape;
            if (shape == null) return false;
            id = e.glId;
            try {
                shape.reset(e.obj, 3553, placeholderId, 1, 1, 1.0f, 1.0f, e.w, e.h);
            } catch (Throwable t) {
                AgentLog.fail("lazy: eviction reset failed for " + e.path, t);
                return false;
            }
            long bytes = e.bytes;
            e.ready = false;
            e.failed = false;
            e.dds = false;
            e.owned = false;
            e.glId = 0;
            e.bytes = 0;
            e.lastSource = null;
            e.attempts.set(0);
            e.evicted++;
            LIVE_BYTES.addAndGet(-bytes);
            EVICTED.incrementAndGet();
            EVICTED_BYTES.addAndGet(bytes);
            touch(e);
        }
        // The proxy already points at the valid placeholder; a failed delete is
        // a VRAM leak, not a dangling id. Count it and let re-materialize fix it.
        if (!GlBridge.deleteTexture(id)) {
            OLD_ID_SKIPPED.incrementAndGet();
            return false;
        }
        return true;
    }

    private static boolean ensurePlaceholder() {
        if (placeholderId > 0) return true;
        if (PLACEHOLDER_FAILED.get()) return false;
        synchronized (LazyTextures.class) {
            if (placeholderId > 0) return true;
            try {
                Object real = syncLoad(PLACEHOLDER_PATH);
                ProxyShape shape = proxyShape;
                if (shape == null) throw new IllegalStateException("proxy shape unavailable");
                int target = shape.target(real);
                int id = shape.glId(real);
                if (target != 3553 || id <= 0) {
                    throw new IllegalStateException("bad placeholder target=" + target + " id=" + id);
                }
                placeholderId = id;
                AgentLog.info("lazy: eviction placeholder resolved id=" + id);
                return true;
            } catch (Throwable t) {
                PLACEHOLDER_FAILED.set(true);
                AgentLog.fail("lazy: eviction placeholder unavailable; eviction disabled", t);
                return false;
            }
        }
    }

    private static void noteMaterialized(ProxyEntry e, long bytes) {
        if (e.bytes == 0 && bytes > 0) {
```

```java
    static ProxyEntry pickSelfTestEntry(java.util.Collection<ProxyEntry> proxies,
                                        LazySkipIndex idx, boolean preferDds) {
        ProxyEntry fallback = null;
        for (ProxyEntry e : proxies) {
            if (e == null || e.ready || e.failed || e.startup || e.obj == null) continue;
            if (isBasicPath(e.path)) continue;
            LazySkipIndex.Entry meta = idx == null ? null : idx.get(e.path);
            if (preferDds && meta != null && meta.hasDds()) return e;
            if (fallback == null) fallback = e;
        }
        return fallback;
    }

    private static void runSelfTest() {
        try {
            ProxyEntry pick = pickSelfTestEntry(PROXIES.values(), index, dds);
            if (pick == null) {
                selftestResult = 3;
                AgentLog.fail("lazy selftest: no candidate proxy", null);
                return;
            }
            Object before = lookup(pick.path);
            if (before == null || !pick.ready || pick.glId <= 0) {
                selftestResult = 2;
                AgentLog.fail("lazy selftest: materialize failed for " + pick.path, null);
                return;
            }
            int firstId = pick.glId;
            if (!evictOne(pick, true) || pick.ready) {
                selftestResult = 2;
                AgentLog.fail("lazy selftest: evict failed for " + pick.path, null);
                return;
            }
            Object after = lookup(pick.path);
            if (after == null || !pick.ready || pick.glId <= 0
                    || pick.rematerialized <= 0) {
                selftestResult = 2;
                AgentLog.fail("lazy selftest: re-materialize failed for " + pick.path, null);
                return;
            }
            if (dds && !pick.dds) {
                selftestResult = 2;
                AgentLog.fail("lazy selftest: DDS path not used for " + pick.path
                        + " (ddsFallback=" + DDS_FALLBACK.get() + ")", null);
                return;
            }
            selftestResult = 1;
            AgentLog.info("lazy selftest: ok path=" + pick.path + " ids=" + firstId
                    + "->" + pick.glId + " dds=" + (pick.dds ? 1 : 0)
                    + " rematerialized=" + pick.rematerialized);
        } catch (Throwable t) {
            selftestResult = 2;
            AgentLog.fail("lazy selftest failed", t);
        }
    }
```

```python
#!/usr/bin/env python3
"""Interleaved control/treatment menu A/B for M2.6 DDS lazy textures.

Control: -Dhypernova.textures.lazy=false
Treatment: -Dhypernova.textures.lazy=true -Dhypernova.textures.lazy.dds=true
Optional: --eviction / --selftest add the corresponding -D flags.

Every round runs through tools/smoke_run.py (launchDirect -> menu anchor ->
linger -> forced exit) and archives that session's log slice. Lazy counters
come from the last "lazy probe: summary" line of the last agent session.
Battle/save/manual visual are explicitly out of scope for this tool.
"""
from __future__ import annotations

import argparse
import json
import re
import subprocess
import sys
from pathlib import Path

TOOLS = Path(__file__).resolve().parent
ROOT = TOOLS.parent
if str(TOOLS) not in sys.path:
    sys.path.insert(0, str(TOOLS))
from smoke_run import PROFILES, free_physical_mb  # noqa: E402

SESSION_ANCHOR = b"Fast Rendering: v0.9."
SUMMARY = "lazy probe: summary "
PAIR_RE = re.compile(r"([A-Za-z][A-Za-z0-9_]*)=([^\s]+)")
SMOKE_TIMEOUT_S = 900
MIN_FREE_MB = 12 * 1024


def stats_from_text(text: str) -> dict:
    lines = text.splitlines()
    start = 0
    for i, line in enumerate(lines):
        if "hypernova agent premain" in line:
            start = i
    out = {}
    for line in lines[start:]:
        pos = line.find(SUMMARY)
        if pos < 0:
            continue
        out = {}
        for key, value in PAIR_RE.findall(line[pos + len(SUMMARY):]):
            try:
                out[key] = int(value)
            except ValueError:
                out[key] = value
    return out


def _flags(lazy: bool, dds: bool, eviction: bool, selftest: bool) -> list[str]:
    args = ["-Dhypernova.textures.lazy=" + ("true" if lazy else "false")]
    if lazy:
        args.append("-Dhypernova.textures.lazy.dds=" + ("true" if dds else "false"))
        if eviction:
            args.append("-Dhypernova.textures.lazy.eviction=true")
        if selftest:
            args.append("-Dhypernova.textures.lazy.selftest=true")
    return args


def run_round(profile: str, lazy: bool, dds: bool, eviction: bool,
              selftest: bool, out: Path, wait: float, linger: float) -> dict:
    out.parent.mkdir(parents=True, exist_ok=True)
    cmd = [sys.executable, "-I", str(TOOLS / "smoke_run.py"),
           "--profile", profile, "--rounds", "1", "--wait-menu", str(wait),
           "--linger", str(linger), "--json-out", str(out.resolve())]
    for arg in _flags(lazy, dds, eviction, selftest):
        cmd.append("--jvm-arg=" + arg)
    proc = subprocess.run(cmd, check=False, cwd=str(ROOT), timeout=SMOKE_TIMEOUT_S)
    try:
        row = json.loads(out.read_text(encoding="utf-8"))[0]
    except Exception as exc:
        row = {"ok": False, "reason": f"json: {exc}"}
    row["returncode"] = proc.returncode
    if proc.returncode != 0:
        row["ok"] = False
    return row


def archive_round(profile: str, tag: str, index: int, out_dir: Path) -> dict:
    result = {"log": None, "failed": 0, "verify": 0, "class_errors": 0,
              "async_errors": 0, "corrupted": 0}
    game = ROOT / PROFILES[profile]["game"]
    log = game / "starsector-core" / "starsector.log"
    if not log.is_file():
        return result
    data = log.read_bytes()
    idx = data.rfind(SESSION_ANCHOR)
    session = data[idx:] if idx >= 0 else data
    dst = out_dir / f"ab-{tag}{index}.log"
    dst.parent.mkdir(parents=True, exist_ok=True)
    dst.write_bytes(session)
    result["log"] = str(dst)
    result["failed"] = session.count(b"Failed to load texture")
    result["verify"] = session.count(b"VerifyError")
    result["class_errors"] = session.count(b"ClassFormatError")
    result["async_errors"] = session.count(b"AsyncException")
    result["corrupted"] = session.count(b"isStateCorrupted")
    return result


def median(values):
    values = sorted(v for v in values if v is not None)
    n = len(values)
    if not n:
        return None
    return values[n // 2] if n % 2 else (values[n // 2 - 1] + values[n // 2]) / 2


def main(argv=None) -> int:
    ap = argparse.ArgumentParser()
    ap.add_argument("--profile", default="miko-lite")
    ap.add_argument("--rounds", type=int, default=3)
    ap.add_argument("--wait-menu", type=float, default=300)
    ap.add_argument("--linger", type=float, default=8)
    ap.add_argument("--agent-log", default="")
    ap.add_argument("--log-dir", default="build/m26/logs")
    ap.add_argument("--eviction", action="store_true")
    ap.add_argument("--selftest", action="store_true")
    ap.add_argument("--dds", action="store_true", default=True)
    ap.add_argument("--no-dds", dest="dds", action="store_false")
    ap.add_argument("--out", required=True)
    args = ap.parse_args(argv)

    free_start = free_physical_mb()
    print(f"[ab] free physical before A/B: {free_start} MB")
    if free_start is not None and free_start < MIN_FREE_MB:
        print(f"[ab] WARNING: free physical memory < {MIN_FREE_MB} MB; A/B may be noisy",
              flush=True)

    agent = Path(args.agent_log) if args.agent_log else (
        ROOT / "Starsector-098-260mods/saves/hypernova/scripts-agent.log")
    if not agent.is_absolute():
        agent = ROOT / agent
    log_dir = Path(args.log_dir)
    if not log_dir.is_absolute():
        log_dir = ROOT / log_dir

    rows = []
    for i in range(1, args.rounds + 1):
        label = f"#{i}/{args.rounds}"
        print(f"\n[ab] {label} control", flush=True)
        c = run_round(args.profile, False, False, False, False,
                      Path(f"build/m26/ab-c{i}.json"), args.wait_menu, args.linger)
        c.update(archive_round(args.profile, "c", i, log_dir))
        print(f"[ab] {label} treatment", flush=True)
        t = run_round(args.profile, True, args.dds, args.eviction, args.selftest,
                      Path(f"build/m26/ab-t{i}.json"), args.wait_menu, args.linger)
        t.update(archive_round(args.profile, "t", i, log_dir))
        stats = stats_from_text(agent.read_text(encoding="utf-8", errors="replace")) \
            if agent.is_file() else {}
        rows.append({"control": c, "treatment": t, "lazy": stats})
        print(f"[ab] {label}: control={c.get('menu_s')}s treatment={t.get('menu_s')}s "
              f"err={c['failed']}/{c['verify']}/{c['class_errors']}|"
              f"{t['failed']}/{t['verify']}/{t['class_errors']} lazy={stats}", flush=True)

    c_med = median([r["control"].get("menu_s") for r in rows])
    t_med = median([r["treatment"].get("menu_s") for r in rows])
    lazy_median = {}
    if rows and all(r["lazy"] for r in rows):
        keys = set().union(*(r["lazy"].keys() for r in rows))
        for key in sorted(keys):
            values = [r["lazy"].get(key) for r in rows
                      if isinstance(r["lazy"].get(key), int)]
            lazy_median[key] = median(values)
    pairs = [round(r["treatment"]["menu_s"] - r["control"]["menu_s"], 1)
             for r in rows
             if r["control"].get("menu_s") is not None
             and r["treatment"].get("menu_s") is not None]
    gates = {
        "all_rounds_ok": all(r["control"].get("ok") and r["treatment"].get("ok")
                             for r in rows),
        "no_texture_errors": all(
            (r[side]["failed"] == 0 and r[side]["verify"] == 0
             and r[side]["class_errors"] == 0 and r[side]["async_errors"] == 0
             and r[side]["corrupted"] == 0)
            for r in rows for side in ("control", "treatment")),
        "treatment_failed_zero": all(r["lazy"].get("failed", 0) == 0 for r in rows),
        "treatment_disabled_zero": all(r["lazy"].get("disabled", 0) == 0 for r in rows),
        "treatment_dim_mismatch_zero": all(
            r["lazy"].get("dimMismatch", 0) == 0 for r in rows),
        "treatment_dds_disabled_zero": all(
            r["lazy"].get("ddsDisabled", 0) == 0 for r in rows),
        "treatment_dds_hit_positive": (lazy_median.get("ddsHit") or 0) > 0,
        "selftest_ok": (not args.selftest) or all(
            r["lazy"].get("selftest") == 1 for r in rows),
    }
    result = {
        "profile": args.profile,
        "rounds": args.rounds,
        "flags": {"dds": args.dds, "eviction": args.eviction, "selftest": args.selftest},
        "free_mb_start": None if free_start is None else round(free_start, 1),
        "rows": rows,
        "control_median": c_med,
        "treatment_median": t_med,
        "delta_s": None if c_med is None or t_med is None else round(t_med - c_med, 2),
        "paired_deltas_s": pairs,
        "paired_median_s": median(pairs),
        "lazy_median": lazy_median or None,
        "gates": gates,
    }
    out_path = Path(args.out)
    out_path.parent.mkdir(parents=True, exist_ok=True)
    out_path.write_text(json.dumps(result, ensure_ascii=False, indent=2), encoding="utf-8")
    print(json.dumps({k: v for k, v in result.items() if k != "rows"},
                     ensure_ascii=False, indent=2))
    return 0 if all(gates.values()) else 1


if __name__ == "__main__":
    raise SystemExit(main())
```
