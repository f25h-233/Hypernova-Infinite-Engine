# M3 启动期裁剪（0–50 s 桶）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 FR 0.9.7rc2 / 260mods 的 60.6 s 基线上，先做出**可复现的 0–50 s 分阶段计时**，再落地**一个可回退、fail-open 的削减杠杆**（FR 目录枚举索引缓存），用同日 A/B 证明它的真实收益；若 G-01'（≤48.5 s）仍不可达，按规格 §7 M3 的停止条件记录证据并修订目标，不做不安全裁剪。

**Architecture:** 本里程碑只动 agent（Form B 的可选增强），不动 `textures`/`scripts` 模块，不改启动档、不改 FR 版本、不改 mod 列表。新增两个互不耦合的 agent 组件：① `StartupTimeline` + transformer，在 FR 的 `ResourceLoaderState` 三个方法入口/出口打时间戳（近零开销），替代高开销 verbose 日志做相位测量；② `FileIndex` + `FileIndexHook` + transformer，把 FR `FileLoaderFast$DirectoryCrawler` 的 229,754 文件枚举结果持久化为带目录 mtime 校验的索引，命中时跳过 `File.listFiles()` 递归，任何失败都退回原始 crawl。所有新代码编译期不引用任何 `com.genir.*` / `com.fs.*` 类，只用反射；`-Dhypernova.fileIndex=false` 或 `hypernova.json` 的 `fileIndex.enabled=false` 一键回滚。

**Tech Stack:** Java 17（major 61）、ASM 9.1（已随 FR agent 分发）、org.json（游戏自带）、Python 3.14（`python -I`）、pytest、JUnit 5、Git Bash（Windows 11）。

**Spec:** `技术笔记-纹理按需加载.md` §7 M3（行 740–747）、§7 M-1c（行 653–658）、F-11（行 255–264）、§10.1 ADR-05（行 822）；M3 开工包 `hn-m3-kickoff.md`；结果基线 `docs/m1f-results.md`。

## Review Focus

1. **索引漏掉新增/删除的文件**：索引构建后，用户在某个 mod 的深层目录新增纹理；若目录 mtime 校验漏了该目录，`FileLoaderFast.loadInputStreams` 会找不到资源（可能崩启动）。测试必须覆盖“新增文件 → 目录 mtime 变化 → 全量 crawl”。
2. **索引损坏/截断/权限失败导致启动失败**：任何 `IOException`、`EOFException`、`ZipException`、反射异常都必须让 `tryLoad` 返回 -1，让 FR 正常 crawl；测试覆盖空文件、半截 gzip、错误 magic、错误版本、超大计数字段。
3. **部分写入后返回 -1 污染 map**：`tryLoad` 若在填充 `cachedFiles` 过程中失败并返回 -1，FR 会在非空 map 上继续 crawl，产生重复条目。实现必须先填充临时 map，全部校验通过后一次性 `clear+putAll`。
4. **FR 线程/类结构变化**：0.9.7 的 `ResourceLoaderState` 方法名/描述符、`DirectoryCrawler.cacheLocations()I`、`FileHandle(File, ResourceLocation)` 若变化，transformer/hook 必须 no-op。测试用同形 fixture 捕捉字节码假设；真机日志出现 `file index ... full crawl` 即 fail-open 生效。
5. **测量把探针开销算进收益**：`miko-lite-phase` 只多两行 INFO，但 A/B 必须用 `miko-lite`（不带探针）跑；相位表只用于归因，不用于 G-01'。
6. **同日漂移**：当前机器比 M-1f 记录慢约 6 s（探针轮 66–67 s vs 60.6 s）。A/B 必须同一天、交替/背靠背跑 control 与 treatment；G-01' 同时报告“相对同日 control”和“相对 M-1f 60.6 s”两个口径，不混用。

```java
package hypernova.agent;

import java.util.ArrayList;
import java.util.Collections;
import java.util.List;
import java.util.concurrent.atomic.AtomicLong;

/**
 * Near-zero-overhead phase marks for the 0-50 s bucket.
 *
 * <p>Log line format is stable because tools/m3_phase.py parses it:
 * {@code timeline: <name> rel_ms=<n> epoch_ms=<n>}.
 *
 * <p>This class must never throw into the game. Marks are used for measurement
 * only; losing one must not change startup behavior.
 */
public final class StartupTimeline {
    private static final AtomicLong START_NANOS = new AtomicLong();
    private static final AtomicLong START_EPOCH = new AtomicLong();
    private static final List<String> MARKS =
            Collections.synchronizedList(new ArrayList<>());

    private StartupTimeline() {
    }

    /** Called once from premain, after AgentLog.init(). */
    public static void start() {
        START_EPOCH.compareAndSet(0, System.currentTimeMillis());
        START_NANOS.compareAndSet(0, System.nanoTime());
    }

    public static void mark(String name) {
        try {
            long startN = START_NANOS.get();
            if (startN == 0) return;
            long relMs = (System.nanoTime() - startN) / 1_000_000;
            MARKS.add(name);
            AgentLog.info("timeline: " + name + " rel_ms=" + relMs
                    + " epoch_ms=" + System.currentTimeMillis());
        } catch (Throwable ignored) {
            // measurement must never affect startup
        }
    }

    static List<String> marksForTest() {
        synchronized (MARKS) {
            return new ArrayList<>(MARKS);
        }
    }

    static void resetForTest() {
        MARKS.clear();
        START_NANOS.set(0);
        START_EPOCH.set(0);
    }
}
```

Create `src/agent/java/hypernova/agent/StartupTimelineTransformer.java`:

```java
package hypernova.agent;

import org.objectweb.asm.ClassReader;
import org.objectweb.asm.ClassVisitor;
import org.objectweb.asm.ClassWriter;
import org.objectweb.asm.Label;
import org.objectweb.asm.MethodVisitor;
import org.objectweb.asm.Opcodes;

import java.lang.instrument.ClassFileTransformer;
import java.security.ProtectionDomain;

/** Marks FR's three startup phases without touching their logic. */
public final class StartupTimelineTransformer implements ClassFileTransformer {
    public static final String TARGET = "com/genir/renderer/overrides/loading/ResourceLoaderState";
    private static final String HOOK = "hypernova/agent/StartupTimeline";

    @Override
    public byte[] transform(ClassLoader loader, String className, Class<?> redefined,
                            ProtectionDomain protectionDomain, byte[] bytes) {
        if (className == null || !TARGET.equals(className) || redefined != null) return null;
        try {
            ClassReader reader = new ClassReader(bytes);
            ClassWriter writer = new ClassWriter(reader, ClassWriter.COMPUTE_MAXS);
            boolean[] patched = {false};
            ClassVisitor visitor = new ClassVisitor(Opcodes.ASM9, writer) {
                @Override
                public MethodVisitor visitMethod(int access, String name, String descriptor,
                                                 String signature, String[] exceptions) {
                    MethodVisitor mv = super.visitMethod(access, name, descriptor, signature, exceptions);
                    String label = labelFor(name, descriptor);
                    if (label == null) return mv;
                    patched[0] = true;
                    return new MethodVisitor(Opcodes.ASM9, mv) {
                        @Override
                        public void visitCode() {
                            super.visitCode();
                            super.visitLdcInsn(label + ".start");
                            super.visitMethodInsn(Opcodes.INVOKESTATIC, HOOK, "mark",
                                    "(Ljava/lang/String;)V", false);
                        }

                        @Override
                        public void visitInsn(int opcode) {
                            if (opcode == Opcodes.RETURN) {
                                super.visitLdcInsn(label + ".end");
                                super.visitMethodInsn(Opcodes.INVOKESTATIC, HOOK, "mark",
                                        "(Ljava/lang/String;)V", false);
                            }
                            super.visitInsn(opcode);
                        }
                    };
                }
            };
            reader.accept(visitor, 0);
            return patched[0] ? writer.toByteArray() : null;
        } catch (Throwable t) {
            AgentLog.fail("startup timeline transform failed; phase marks disabled", t);
            return null;
        }
    }

    private static String labelFor(String name, String descriptor) {
        if ("initFileLoaders".equals(name) && "()V".equals(descriptor)) return "initFileLoaders";
        if ("initSpecStore".equals(name) && "(Ljava/util/Map;)V".equals(descriptor)) return "initSpecStore";
        if ("initMods".equals(name) && "()V".equals(descriptor)) return "initMods";
        return null;
    }
}
```

```python
#!/usr/bin/env python3
"""Derive a launch profile with a different log4j config, byte-for-byte.

The 260mods launch profiles are CRLF and the agent must stay before FR.
This tool only swaps the log4j properties filename; it never rewrites the
file, so line endings and argument order are preserved.
"""
from __future__ import annotations

import argparse
from pathlib import Path

TOKEN = b"mikohime/mikohime.properties"


def derive(src: Path, dst: Path, props: str) -> None:
    data = src.read_bytes()
    count = data.count(TOKEN)
    if count != 1:
        raise ValueError(f"expected exactly one {TOKEN!r} token, found {count}")
    if b"hn-verbose" in data or b"hn-phase" in data:
        raise ValueError("source already points at a probe log4j config")
    dst.write_bytes(data.replace(TOKEN, props.encode("ascii")))


def main(argv=None) -> int:
    ap = argparse.ArgumentParser()
    ap.add_argument("--src", required=True)
    ap.add_argument("--out", required=True)
    ap.add_argument("--props", default="mikohime/hn-phase.properties")
    args = ap.parse_args(argv)
    derive(Path(args.src), Path(args.out), args.props)
    print(f"wrote {args.out}")
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```

```python
#!/usr/bin/env python3
"""Parse a Starsector session into 0-50 s phase timings.

Never assumes the M-1c (FR 0.9.5) table. Inputs may be rotated logs; the
parser takes the LAST Fast Rendering session and the LAST agent premain
session. Output is JSON so docs and the ledger can cite exact numbers.
"""
from __future__ import annotations

import argparse
import json
from pathlib import Path

SESSION_RE = __import__("re").compile(
    r"^\s*(\d+)\s+\[[^\]]+\]\s+INFO\s+com\.genir\.renderer\.agent\.Agent\s+"
    r"-\s+Fast Rendering: v0\.9\.")
MENU_RE = __import__("re").compile(
    r"^\s*(\d+)\s+\[[^\]]+\]\s+INFO\s+sound\.H\s+"
    r"-\s+Playing music with id \[miscallenous_main_menu\.ogg\]")
CRAWL_RE = __import__("re").compile(r"Cached (\d+) files in (\d+)ms")
TIMELINE_RE = __import__("re").compile(
    r"timeline:\s*(\S+)\s+rel_ms=(\d+)\s+epoch_ms=(\d+)")
PRELOAD_RE = __import__("re").compile(
    r"scripts cache preloaded:.*entries=(\d+).*in (\d+) ms")


def _read(paths: list[str]) -> str:
    return "".join(Path(p).read_bytes() for p in paths).decode("utf-8", "replace")


def parse_session(text: str):
    lines = text.splitlines()
    starts = [i for i, line in enumerate(lines) if SESSION_RE.match(line)]
    if not starts:
        raise SystemExit("no Fast Rendering session anchor in log")
    session = lines[starts[-1]:]
    start_ms = int(SESSION_RE.match(session[0]).group(1))
    menu_ms = None
    for line in session:
        m = MENU_RE.match(line)
        if m:
            menu_ms = int(m.group(1)) - start_ms
    crawl = None
    for line in session:
        m = CRAWL_RE.search(line)
        if m:
            crawl = {"files": int(m.group(1)), "ms": int(m.group(2))}
    return session, start_ms, menu_ms, crawl


def parse_agent(text: str):
    lines = text.splitlines()
    starts = [i for i, line in enumerate(lines) if "hypernova agent premain" in line]
    session = lines[starts[-1]:] if starts else lines
    marks: dict[str, dict[str, int]] = {}
    for line in session:
        m = TIMELINE_RE.search(line)
        if m:
            marks[m.group(1)] = {"rel_ms": int(m.group(2)), "epoch_ms": int(m.group(3))}
    preload = None
    for line in session:
        m = PRELOAD_RE.search(line)
        if m:
            preload = {"entries": int(m.group(1)), "ms": int(m.group(2))}
    return marks, preload


def phases(marks: dict[str, dict[str, int]]) -> dict[str, int]:
    out: dict[str, int] = {}
    for name in ("initFileLoaders", "initSpecStore", "initMods"):
        start = marks.get(name + ".start")
        end = marks.get(name + ".end")
        if start and end:
            out[name] = end["rel_ms"] - start["rel_ms"]
    return out


def main(argv=None) -> int:
    ap = argparse.ArgumentParser()
    ap.add_argument("--log", action="append", required=True)
    ap.add_argument("--agent-log", action="append", default=[])
    ap.add_argument("--json-out", default="")
    args = ap.parse_args(argv)
    _, start_ms, menu_ms, crawl = parse_session(_read(args.log))
    marks, preload = ({}, None)
    if args.agent_log:
        marks, preload = parse_agent(_read(args.agent_log))
    result = {
        "session_start_ms": start_ms,
        "menu_ms": menu_ms,
        "crawl": crawl,
        "timeline": marks,
        "phases_ms": phases(marks),
        "preload": preload,
    }
    payload = json.dumps(result, ensure_ascii=False, indent=2)
    print(payload)
    if args.json_out:
        Path(args.json_out).write_text(payload + "\n", encoding="utf-8")
    return 0 if menu_ms is not None else 1


if __name__ == "__main__":
    raise SystemExit(main())
```

```java
package hypernova.agent;

import java.io.BufferedInputStream;
import java.io.BufferedOutputStream;
import java.io.DataInputStream;
import java.io.DataOutputStream;
import java.io.EOFException;
import java.io.IOException;
import java.nio.charset.StandardCharsets;
import java.nio.file.AtomicMoveNotSupportedException;
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.StandardCopyOption;
import java.util.ArrayList;
import java.util.List;
import java.util.Objects;
import java.util.zip.GZIPInputStream;
import java.util.zip.GZIPOutputStream;

/**
 * Persistent file-enumeration index. Compile-time independent of FR/game classes.
 *
 * <p>Format (gzip): magic, version, locations[type,path,isMod], dirs[path,mtime],
 * entries[key,filePath,locationIndex]. Any decode failure returns null; callers
 * must fall back to the original FR crawl.
 */
public final class FileIndex {
    static final int MAGIC = 0x484E4649; // "HNFI"
    static final int VERSION = 1;
    private static final int MAX_RECORDS = 2_000_000;
    private static final int MAX_STRING = 1 << 20;

    public record Location(String type, String path, boolean isMod) {
        public Location {
            Objects.requireNonNull(type, "type");
            Objects.requireNonNull(path, "path");
        }
    }

    public record Dir(String path, long mtime) {
        public Dir {
            Objects.requireNonNull(path, "path");
        }
    }

    public record Entry(String key, String filePath, int locationIndex) {
        public Entry {
            Objects.requireNonNull(key, "key");
            Objects.requireNonNull(filePath, "filePath");
        }
    }

    private final List<Location> locations;
    private final List<Dir> dirs;
    private final List<Entry> entries;

    public FileIndex(List<Location> locations, List<Dir> dirs, List<Entry> entries) {
        this.locations = List.copyOf(locations);
        this.dirs = List.copyOf(dirs);
        this.entries = List.copyOf(entries);
    }

    public List<Location> locations() { return locations; }
    public List<Dir> dirs() { return dirs; }
    public List<Entry> entries() { return entries; }

    /** Returns null for absent, corrupt, truncated, or unknown-version files. */
    public static FileIndex read(Path file) {
        if (file == null || !Files.isRegularFile(file)) return null;
        try (DataInputStream in = new DataInputStream(
                new GZIPInputStream(new BufferedInputStream(Files.newInputStream(file))))) {
            if (in.readInt() != MAGIC) return null;
            if (in.readInt() != VERSION) return null;

            int locationCount = count(in);
            List<Location> locations = new ArrayList<>(locationCount);
            for (int i = 0; i < locationCount; i++) {
                locations.add(new Location(readString(in), readString(in), in.readBoolean()));
            }
            int dirCount = count(in);
            List<Dir> dirs = new ArrayList<>(dirCount);
            for (int i = 0; i < dirCount; i++) {
                dirs.add(new Dir(readString(in), in.readLong()));
            }
            int entryCount = count(in);
            List<Entry> entries = new ArrayList<>(entryCount);
            for (int i = 0; i < entryCount; i++) {
                entries.add(new Entry(readString(in), readString(in), in.readInt()));
            }
            return new FileIndex(locations, dirs, entries);
        } catch (IOException | RuntimeException e) {
            return null;
        }
    }

    public void write(Path file) throws IOException {
        Path parent = file.toAbsolutePath().getParent();
        if (parent != null) Files.createDirectories(parent);
        Path tmp = file.resolveSibling(file.getFileName() + ".tmp");
        try (DataOutputStream out = new DataOutputStream(
                new GZIPOutputStream(new BufferedOutputStream(Files.newOutputStream(tmp))))) {
            out.writeInt(MAGIC);
            out.writeInt(VERSION);
            out.writeInt(locations.size());
            for (Location location : locations) {
                writeString(out, location.type());
                writeString(out, location.path());
                out.writeBoolean(location.isMod());
            }
            out.writeInt(dirs.size());
            for (Dir dir : dirs) {
                writeString(out, dir.path());
                out.writeLong(dir.mtime());
            }
            out.writeInt(entries.size());
            for (Entry entry : entries) {
                writeString(out, entry.key());
                writeString(out, entry.filePath());
                out.writeInt(entry.locationIndex());
            }
        }
        try {
            Files.move(tmp, file, StandardCopyOption.REPLACE_EXISTING,
                    StandardCopyOption.ATOMIC_MOVE);
        } catch (AtomicMoveNotSupportedException e) {
            Files.move(tmp, file, StandardCopyOption.REPLACE_EXISTING);
        }
    }

    /**
     * Returns the first directory whose mtime changed or disappeared, else null.
     * Windows directory mtime changes when entries are added/removed, which is
     * exactly the invalidation condition for an enumeration cache.
     */
    public String firstMismatchedDir() {
        for (Dir dir : dirs) {
            long now = new java.io.File(dir.path()).lastModified();
            if (now != dir.mtime()) return dir.path();
        }
        return null;
    }

    private static int count(DataInputStream in) throws IOException {
        int n = in.readInt();
        if (n < 0 || n > MAX_RECORDS) throw new IOException("bad record count: " + n);
        return n;
    }

    private static String readString(DataInputStream in) throws IOException {
        int n = in.readInt();
        if (n < 0 || n > MAX_STRING) throw new IOException("bad string length: " + n);
        byte[] bytes = new byte[n];
        in.readFully(bytes);
        return new String(bytes, StandardCharsets.UTF_8);
    }

    private static void writeString(DataOutputStream out, String value) throws IOException {
        byte[] bytes = value.getBytes(StandardCharsets.UTF_8);
        out.writeInt(bytes.length);
        out.write(bytes);
    }
}
```

```java
package com.genir.renderer.overrides.loading;

import com.fs.util.FileLoader;

import java.io.File;
import java.nio.file.Paths;
import java.util.ArrayList;
import java.util.HashMap;

import java.util.Locale;
import java.util.Map;

/** Test fixture with the same inner-class/method shape as FR 0.9.7. */
public class FileLoaderFast {
    private final List<FileLoader.ResourceLocation> allLocations;
    private final Map<String, List<ResourceHandle.FileHandle>> cachedFiles = new HashMap<>();

    public FileLoaderFast(List<FileLoader.ResourceLocation> allLocations) {
        this.allLocations = allLocations;
    }

    public int crawl() {
        return new DirectoryCrawler().cacheLocations();
    }

    private String getLocationPath(FileLoader.ResourceLocation location) {
        return location.ResourceLocation_path;
    }

    private String normalize(String path) {
        if (path.startsWith("/")) path = path.substring(1);
        if (path.startsWith("\\")) path = path.substring(1);
        path = path.trim();
        path = Paths.get(path).normalize().toString().replace("\\", "/");
        if (path.endsWith("/")) path = path.substring(0, path.length() - 1);
        if (path.endsWith(".")) path = path.substring(0, path.length() - 1);
        return path.toLowerCase(Locale.ROOT);
    }

    private final class DirectoryCrawler {
        private final List<Object> collector = new ArrayList<>();

        private int cacheLocations() {
            for (FileLoader.ResourceLocation location : allLocations) {
                walk(new File(getLocationPath(location)), location);
            }
            int count = 0;
            for (Object item : collector) {
                if (item instanceof List<?> list) {
                    for (Object handle : list) {
                        saveFile((ResourceHandle.FileHandle) handle);
                        count++;
                    }
                } else {
                    saveFile((ResourceHandle.FileHandle) item);
                    count++;
                }
            }
            return count;
        }

        private void walk(File file, FileLoader.ResourceLocation location) {
            collector.add(new ResourceHandle.FileHandle(file, location));
            File[] children = file.listFiles();
            if (children != null) {
                for (File child : children) walk(child, location);
            }
        }

        private void saveFile(ResourceHandle.FileHandle handle) {
            String locationPath = new File(getLocationPath(handle.location)).getAbsolutePath();
            String key = normalize(handle.file.getPath().replace(locationPath, ""));
            if (key.isEmpty()) return;
            cachedFiles.computeIfAbsent(key, k -> new ArrayList<>()).add(handle);
        }
    }
}
```

```java
package hypernova.agent;

import org.json.JSONObject;

import java.io.File;
import java.lang.reflect.Constructor;
import java.lang.reflect.Field;
import java.nio.file.Files;
import java.nio.file.Path;
import java.util.ArrayList;
import java.util.Collections;
import java.util.HashMap;
import java.util.IdentityHashMap;
import java.util.LinkedHashSet;
import java.util.List;
import java.util.Map;
import java.util.Set;
import java.util.concurrent.atomic.AtomicInteger;

/**
 * Injects a persisted directory enumeration into FR FileLoaderFast.DirectoryCrawler.
 *
 * <p>Everything is reflective: this class must compile without FR on the classpath.
 * Any mismatch (field rename, constructor change, corrupt index, changed directory)
 * returns -1 and lets FR perform its original crawl. It must never throw into the game.
 */
public final class FileIndexHook {
    private static final String FH_CLASS =
            "com.genir.renderer.overrides.loading.ResourceHandle$FileHandle";
    private static volatile RuntimeContext context;
    private static final Set<Object> LOADED = Collections.newSetFromMap(new IdentityHashMap<>());
    private static final AtomicInteger LAST_LOADED = new AtomicInteger(Integer.MIN_VALUE);

    private FileIndexHook() {
    }

    public static void setContext(RuntimeContext ctx) {
        context = ctx;
    }

    static boolean enabled() {
        String prop = System.getProperty("hypernova.fileIndex");
        if (prop != null) return Boolean.parseBoolean(prop);
        RuntimeContext ctx = context;
        if (ctx == null) return true;
        Path cfg = ctx.gameRoot().resolve(
                "mods/hypernova_infinite_engine/data/config/hypernova/hypernova.json");
        if (!Files.isRegularFile(cfg)) return true;
        try {
            JSONObject root = new JSONObject(Files.readString(cfg));
            JSONObject section = root.optJSONObject("fileIndex");
            return section == null || section.optBoolean("enabled", true);
        } catch (Throwable t) {
            AgentLog.fail("file index config parse failed; enabled by default", t);
            return true;
        }
    }

    /** Returns the cached entry count, or -1 to let FR run its full crawl. */
    public static int tryLoad(Object crawler) {
        if (!enabled()) return -1;
        RuntimeContext ctx = context;
        if (ctx == null) return -1;
        try {
            Object outer = get(crawler, "this$0");
            if (outer == null) return -1;
            @SuppressWarnings("unchecked")
            Map<String, List<Object>> target = (Map<String, List<Object>>) get(outer, "cachedFiles");
            @SuppressWarnings("unchecked")
            List<Object> locations = (List<Object>) get(outer, "allLocations");
            if (target == null || locations == null || locations.isEmpty()) return -1;

            Path indexFile = indexFile(ctx);
            FileIndex index = FileIndex.read(indexFile);
            if (index == null) return -1;

            List<FileIndex.Location> current = locationKeys(locations);
            if (current == null || current.size() != index.locations().size()) return -1;
            Map<FileIndex.Location, Integer> currentIndex = new HashMap<>();
            for (int i = 0; i < current.size(); i++) currentIndex.put(current.get(i), i);
            int[] remap = new int[index.locations().size()];
            for (int i = 0; i < remap.length; i++) {
                Integer j = currentIndex.get(index.locations().get(i));
                if (j == null) return -1;
                remap[i] = j;
            }

            String changed = index.firstMismatchedDir();
            if (changed != null) {
                AgentLog.info("file index: directory changed [" + changed + "]; full crawl");
                return -1;
            }
            Constructor<?> ctor = fileHandleCtor();
            if (ctor == null) return -1;

            // Build into a temporary map: a failed load must not pollute cachedFiles.
            Map<String, List<Object>> loaded = new HashMap<>();
            for (FileIndex.Entry entry : index.entries()) {
                if (entry.locationIndex() < 0 || entry.locationIndex() >= remap.length) return -1;
                Object location = locations.get(remap[entry.locationIndex()]);
                if (!prefixOk(entry.filePath(), location)) return -1;
                Object handle = ctor.newInstance(new File(entry.filePath()), location);
                loaded.computeIfAbsent(entry.key(), k -> new ArrayList<>()).add(handle);
            }
            target.clear();
            target.putAll(loaded);
            LOADED.add(crawler);
            LAST_LOADED.set(index.entries().size());
            AgentLog.info("file index: loaded entries=" + index.entries().size()
                    + ", dirs=" + index.dirs().size() + ", bytes=" + Files.size(indexFile));
            return index.entries().size();
        } catch (Throwable t) {
            AgentLog.fail("file index load failed; falling back to full crawl", t);
            return -1;
        }
    }

    /** Persists a freshly crawled map. No-op when disabled, already loaded, or failed. */
    public static void save(Object crawler, int count) {
        if (!enabled() || count <= 0 || LOADED.contains(crawler)) return;
        RuntimeContext ctx = context;
        if (ctx == null) return;
        try {
            Object outer = get(crawler, "this$0");
            if (outer == null) return;
            @SuppressWarnings("unchecked")
            Map<String, List<Object>> map = (Map<String, List<Object>>) get(outer, "cachedFiles");
            @SuppressWarnings("unchecked")
            List<Object> locations = (List<Object>) get(outer, "allLocations");
            if (map == null || locations == null || locations.isEmpty()) return;
            List<FileIndex.Location> keys = locationKeys(locations);
            if (keys == null) return;

            IdentityHashMap<Object, Integer> index = new IdentityHashMap<>();
            for (int i = 0; i < locations.size(); i++) index.put(locations.get(i), i);

            List<FileIndex.Entry> entries = new ArrayList<>(count);
            Set<String> dirs = new LinkedHashSet<>();
            for (Map.Entry<String, List<Object>> entry : map.entrySet()) {
                for (Object handle : entry.getValue()) {
                    File file = (File) get(handle, "file");
                    Object location = get(handle, "location");
                    Integer locationIndex = index.get(location);
                    if (file == null || locationIndex == null) return;
                    entries.add(new FileIndex.Entry(entry.getKey(), file.getPath(), locationIndex));
                    File parent = file.getParentFile();
                    if (parent != null) dirs.add(parent.getPath());
                }
            }
            for (Object location : locations) {
                Object path = get(location, "ResourceLocation_path");
                if (path instanceof String s && new File(s).isDirectory()) dirs.add(s);
            }
            List<FileIndex.Dir> dirList = new ArrayList<>(dirs.size());
            for (String dir : dirs) {
                long mtime = new File(dir).lastModified();
                if (mtime == 0) return;
                dirList.add(new FileIndex.Dir(dir, mtime));
            }
            new FileIndex(keys, dirList, entries).write(indexFile(ctx));
            AgentLog.info("file index: written entries=" + entries.size()
                    + ", dirs=" + dirList.size());
        } catch (Throwable t) {
            AgentLog.fail("file index save failed; next launch will crawl", t);
        }
    }

    static int lastLoadedForTest() {
        return LAST_LOADED.get();
    }

    static void resetForTest() {
        LOADED.clear();
        LAST_LOADED.set(Integer.MIN_VALUE);
        context = null;
    }

    private static Path indexFile(RuntimeContext ctx) {
        return ctx.cacheRoot().getParent().resolve("file-index.idx.gz");
    }

    private static Object get(Object target, String name) {
        try {
            Field field = target.getClass().getDeclaredField(name);
            field.setAccessible(true);
            return field.get(target);
        } catch (NoSuchFieldException e) {
            throw new IllegalStateException("field not found: " + name, e);
        } catch (ReflectiveOperationException e) {
            throw new IllegalStateException("field access failed: " + name, e);
        }
    }

    private static List<FileIndex.Location> locationKeys(List<Object> locations) {
        try {
            List<FileIndex.Location> out = new ArrayList<>(locations.size());
            for (Object location : locations) {
                Object type = get(location, "ResourceLocation_type");
                Object path = get(location, "ResourceLocation_path");
                Object isMod = get(location, "ResourceLocation_isMod");
                if (!(type instanceof Enum<?> t) || !(path instanceof String p)
                        || !(isMod instanceof Boolean m)) return null;
                out.add(new FileIndex.Location(t.name(), p, m));
            }
            return out;
        } catch (Throwable t) {
            return null;
        }
    }

    private static Constructor<?> fileHandleCtor() {
        try {
            Class<?> cls = Class.forName(FH_CLASS, false, ClassLoader.getSystemClassLoader());
            for (Constructor<?> ctor : cls.getConstructors()) {
                Class<?>[] params = ctor.getParameterTypes();
                if (params.length == 2 && params[0] == File.class) return ctor;
            }
        } catch (Throwable ignored) {
            // FR missing or class shape changed: fail open.
        }
        return null;
    }

    private static boolean prefixOk(String filePath, Object location) {
        try {
            Object path = get(location, "ResourceLocation_path");
            if (!(path instanceof String base) || base.isBlank()) return true;
            Path file = Path.of(filePath).toAbsolutePath().normalize();
            Path root = Path.of(base).toAbsolutePath().normalize();
            return file.startsWith(root);
        } catch (Throwable t) {
            return false;
        }
    }
}
```

Create `src/agent/java/hypernova/agent/FileIndexTransformer.java`:

```java
package hypernova.agent;

import org.objectweb.asm.ClassReader;
import org.objectweb.asm.ClassVisitor;
import org.objectweb.asm.ClassWriter;
import org.objectweb.asm.Label;
import org.objectweb.asm.MethodVisitor;
import org.objectweb.asm.Opcodes;

import java.lang.instrument.ClassFileTransformer;
import java.security.ProtectionDomain;

/** Replaces FR's directory crawl with a cached lookup when valid. */
public final class FileIndexTransformer implements ClassFileTransformer {
    public static final String TARGET =
            "com/genir/renderer/overrides/loading/FileLoaderFast$DirectoryCrawler";
    private static final String HOOK = "hypernova/agent/FileIndexHook";

    @Override
    public byte[] transform(ClassLoader loader, String className, Class<?> redefined,
                            ProtectionDomain protectionDomain, byte[] bytes) {
        if (className == null || !TARGET.equals(className) || redefined != null) return null;
        try {
            ClassReader reader = new ClassReader(bytes);
            ClassWriter writer = new ClassWriter(reader, ClassWriter.COMPUTE_MAXS);
            boolean[] patched = {false};
            ClassVisitor visitor = new ClassVisitor(Opcodes.ASM9, writer) {
                @Override
                public MethodVisitor visitMethod(int access, String name, String descriptor,
                                                 String signature, String[] exceptions) {
                    MethodVisitor mv = super.visitMethod(access, name, descriptor, signature, exceptions);
                    if (!"cacheLocations".equals(name) || !"()I".equals(descriptor)) return mv;
                    patched[0] = true;
                    return new MethodVisitor(Opcodes.ASM9, mv) {
                        @Override
                        public void visitCode() {
                            super.visitCode();
                            super.visitVarInsn(Opcodes.ALOAD, 0);
                            super.visitMethodInsn(Opcodes.INVOKESTATIC, HOOK, "tryLoad",
                                    "(Ljava/lang/Object;)I", false);
                            super.visitVarInsn(Opcodes.ISTORE, 1);
                            super.visitVarInsn(Opcodes.ILOAD, 1);
                            Label continueCrawl = new Label();
                            super.visitJumpInsn(Opcodes.IFLT, continueCrawl);
                            super.visitVarInsn(Opcodes.ILOAD, 1);
                            super.visitInsn(Opcodes.IRETURN);
                            super.visitLabel(continueCrawl);
                            super.visitFrame(Opcodes.F_SAME, 0, null, 0, null);
                        }

                        @Override
                        public void visitInsn(int opcode) {
                            if (opcode == Opcodes.IRETURN) {
                                super.visitVarInsn(Opcodes.ALOAD, 0);
                                super.visitVarInsn(Opcodes.ILOAD, 1);
                                super.visitMethodInsn(Opcodes.INVOKESTATIC, HOOK, "save",
                                        "(Ljava/lang/Object;I)V", false);
                            }
                            super.visitInsn(opcode);
                        }
                    };
                }
            };
            reader.accept(visitor, 0);
            return patched[0] ? writer.toByteArray() : null;
        } catch (Throwable t) {
            AgentLog.fail("file index transform failed; FR crawl stays untouched", t);
            return null;
        }
    }
}
```

```python
#!/usr/bin/env python3
"""Compute medians and deltas from two smoke_run JSON files."""
from __future__ import annotations

import argparse
import json
import statistics
from pathlib import Path


def load_menu_s(path: Path) -> list[float]:
    rows = json.loads(Path(path).read_text(encoding="utf-8"))
    values = [float(r["menu_s"]) for r in rows if r.get("ok")]
    if not values:
        raise SystemExit(f"no ok rounds in {path}")
    return values


def summarize(control: Path, treatment: Path) -> dict:
    c = load_menu_s(control)
    t = load_menu_s(treatment)
    cm = statistics.median(c)
    tm = statistics.median(t)
    return {
        "control_s": c,
        "treatment_s": t,
        "control_median_s": cm,
        "treatment_median_s": tm,
        "delta_s": round(cm - tm, 1),
        "delta_pct": round((cm - tm) / cm * 100, 2),
    }


def main(argv=None) -> int:
    ap = argparse.ArgumentParser()
    ap.add_argument("--control", required=True)
    ap.add_argument("--treatment", required=True)
    ap.add_argument("--json-out", default="")
    args = ap.parse_args(argv)
    result = summarize(Path(args.control), Path(args.treatment))
    payload = json.dumps(result, ensure_ascii=False, indent=2)
    print(payload)
    if args.json_out:
        Path(args.json_out).write_text(payload + "\n", encoding="utf-8")
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```

## Addendum A（自审修正，覆盖 Task 4 的 `FileIndexHook` 同名代码块）

### A.1 问题

Task 4 初稿把所有 location 的目录都纳入 mtime 校验。`ABSOLUTE_AND_CWD` 覆盖 `starsector-core`（每轮写 `starsector.log`/`gc-miko.log`）、`saves`（每轮可能写存档/telemetry）、`saves/hypernova`（agent 自己写 `file-index.idx.gz`）——这些目录的 mtime **每轮必变**，索引会在下一次启动时判定失效，杠杆永远不命中；若为了命中去掉校验，新存档又不可见。

### A.2 修正设计

- **只缓存 `DIRECTORY`（mod）location 的条目和目录 mtime**；mod 根在两次启动之间稳定，mtime 校验能捕捉新增/删除文件。
- 命中时，**非 mod 根（`ABSOLUTE_AND_CWD`：game core 5,554 文件 + saves 98 + enabled_mods + mikohime 50）由 hook 每次重新枚举**（约 0.2–0.5 s），因此新日志、新存档、新 enabled_mods 永远可见。
- 枚举顺序按当前 `allLocations` 顺序：`DIRECTORY` location 回放缓存条目（collector 顺序），`ABSOLUTE_AND_CWD` location 现场 walk（PWD → saves → enabled_mods.json → mikohime，与 FR `planEnumeration` 同序）。这保留了 `loadInputStreams` 对 core/mod 同名资源的优先级。
- `save` 遍历 `DirectoryCrawler.collector`（原始顺序），只把 `DIRECTORY` 条目写入索引；`dirs` 只收 mod 目录与其父目录。

```java
package hypernova.agent;

import org.json.JSONObject;

import java.io.File;
import java.lang.reflect.Constructor;
import java.lang.reflect.Field;
import java.nio.file.Files;
import java.nio.file.Path;
import java.util.ArrayList;
import java.util.Collections;
import java.util.HashMap;

import java.util.LinkedHashSet;

import java.util.Locale;

import java.util.Set;

public final class FileIndexHook {
    private static final String FH_CLASS =
            "com.genir.renderer.overrides.loading.ResourceHandle$FileHandle";
    private static volatile RuntimeContext context;
    private static final Set<Object> LOADED = Collections.newSetFromMap(new IdentityHashMap<>());
    private static final AtomicInteger LAST_LOADED = new AtomicInteger(Integer.MIN_VALUE);

    private FileIndexHook() {
    }

    public static void setContext(RuntimeContext ctx) {
        context = ctx;
    }

    static boolean enabled() {
        String prop = System.getProperty("hypernova.fileIndex");
        if (prop != null) return Boolean.parseBoolean(prop);
        RuntimeContext ctx = context;
        if (ctx == null) return true;
        Path cfg = ctx.gameRoot().resolve(
                "mods/hypernova_infinite_engine/data/config/hypernova/hypernova.json");
        if (!Files.isRegularFile(cfg)) return true;
        try {
            JSONObject root = new JSONObject(Files.readString(cfg));
            JSONObject section = root.optJSONObject("fileIndex");
            return section == null || section.optBoolean("enabled", true);
        } catch (Throwable t) {
            AgentLog.fail("file index config parse failed; enabled by default", t);
            return true;
        }
    }

    public static int tryLoad(Object crawler) {
        if (!enabled()) return -1;
        RuntimeContext ctx = context;
        if (ctx == null) return -1;
        try {
            Object outer = get(crawler, "this$0");
            if (outer == null) return -1;
            @SuppressWarnings("unchecked")
            Map<String, List<Object>> target = (Map<String, List<Object>>) get(outer, "cachedFiles");
            @SuppressWarnings("unchecked")
            List<Object> locations = (List<Object>) get(outer, "allLocations");
            if (target == null || locations == null || locations.isEmpty()) return -1;

            FileIndex index = FileIndex.read(indexFile(ctx));
            if (index == null) return -1;
            List<FileIndex.Location> current = locationKeys(locations);
            if (current == null || current.size() != index.locations().size()) return -1;

            Map<FileIndex.Location, Integer> stored = new HashMap<>();
            for (int i = 0; i < index.locations().size(); i++) {
                stored.put(index.locations().get(i), i);
            }
            int[] storedForCurrent = new int[current.size()];
            for (int i = 0; i < current.size(); i++) {
                Integer s = stored.get(current.get(i));
                if (s == null) return -1;
                storedForCurrent[i] = s;
            }

            String changed = index.firstMismatchedDir();
            if (changed != null) {
                AgentLog.info("file index: directory changed [" + changed + "]; full crawl");
                return -1;
            }
            Constructor<?> ctor = fileHandleCtor();
            if (ctor == null) return -1;

            Map<Integer, List<FileIndex.Entry>> cached = new HashMap<>();
            for (FileIndex.Entry entry : index.entries()) {
                cached.computeIfAbsent(entry.locationIndex(), k -> new ArrayList<>()).add(entry);
            }

            Map<String, List<Object>> loaded = new HashMap<>();
            int total = 0;
            for (int i = 0; i < locations.size(); i++) {
                Object location = locations.get(i);
                String type = typeName(location);
                if ("DIRECTORY".equals(type)) {
                    List<FileIndex.Entry> entries = cached.get(storedForCurrent[i]);
                    if (entries == null) {
                        total += crawlDirectory(location, loaded, ctor);
                    } else {
                        for (FileIndex.Entry entry : entries) {
                            if (!prefixOk(entry.filePath(), location)) return -1;
                            add(loaded, ctor, location, entry.key(), entry.filePath());
                            total++;
                        }
                    }
                } else if ("ABSOLUTE_AND_CWD".equals(type)) {
                    total += crawlAbsolute(location, loaded, ctor);
                }
                // CLASSPATH and anything else are excluded by FR's own crawler.
            }
            target.clear();
            target.putAll(loaded);
            LOADED.add(crawler);
            LAST_LOADED.set(total);
            AgentLog.info("file index: loaded mod_entries=" + index.entries().size()
                    + ", total_entries=" + total + ", dirs=" + index.dirs().size()
                    + ", bytes=" + Files.size(indexFile(ctx)));
            return total;
        } catch (Throwable t) {
            AgentLog.fail("file index load failed; falling back to full crawl", t);
            return -1;
        }
    }

    public static void save(Object crawler, int count) {
        if (!enabled() || count <= 0 || LOADED.contains(crawler)) return;
        RuntimeContext ctx = context;
        if (ctx == null) return;
        try {
            Object outer = get(crawler, "this$0");
            if (outer == null) return;
            @SuppressWarnings("unchecked")
            List<Object> locations = (List<Object>) get(outer, "allLocations");
            @SuppressWarnings("unchecked")
            List<Object> collector = (List<Object>) get(crawler, "collector");
            if (locations == null || collector == null || locations.isEmpty()) return;
            List<FileIndex.Location> keys = locationKeys(locations);
            if (keys == null) return;

            IdentityHashMap<Object, Integer> index = new IdentityHashMap<>();
            for (int i = 0; i < locations.size(); i++) index.put(locations.get(i), i);

            List<FileIndex.Entry> entries = new ArrayList<>(count);
            Set<String> dirs = new LinkedHashSet<>();
            for (Object item : collector) {
                if (item instanceof List<?> list) {
                    for (Object handle : list) addSaved(handle, index, entries, dirs);
                } else {
                    addSaved(item, index, entries, dirs);
                }
            }
            for (FileIndex.Location location : keys) {
                if ("DIRECTORY".equals(location.type())) {
                    File root = new File(location.path());
                    if (root.isDirectory()) dirs.add(root.getPath());
                }
            }
            List<FileIndex.Dir> dirList = new ArrayList<>(dirs.size());
            for (String dir : dirs) {
                long mtime = new File(dir).lastModified();
                if (mtime == 0) return;
                dirList.add(new FileIndex.Dir(dir, mtime));
            }
            new FileIndex(keys, dirList, entries).write(indexFile(ctx));
            AgentLog.info("file index: written entries=" + entries.size()
                    + ", dirs=" + dirList.size());
        } catch (Throwable t) {
            AgentLog.fail("file index save failed; next launch will crawl", t);
        }
    }

    static int lastLoadedForTest() {
        return LAST_LOADED.get();
    }

    static void resetForTest() {
        LOADED.clear();
        LAST_LOADED.set(Integer.MIN_VALUE);
        context = null;
    }

    private static void addSaved(Object handle, IdentityHashMap<Object, Integer> index,
                                 List<FileIndex.Entry> entries, Set<String> dirs) {
        try {
            Object location = get(handle, "location");
            if (!"DIRECTORY".equals(typeName(location))) return; // non-mod roots are re-crawled
            File file = (File) get(handle, "file");
            Integer locationIndex = index.get(location);
            if (file == null || locationIndex == null) return;
            String key = keyFor(file, location);
            if (key.isEmpty()) return;
            entries.add(new FileIndex.Entry(key, file.getPath(), locationIndex));
            File parent = file.getParentFile();
            if (parent != null) dirs.add(parent.getPath());
        } catch (Throwable ignored) {
            // One bad handle must not abort the whole index.
        }
    }

    private static int crawlDirectory(Object location, Map<String, List<Object>> loaded,
                                      Constructor<?> ctor) throws Exception {
        Object path = get(location, "ResourceLocation_path");
        if (!(path instanceof String p)) return 0;
        return walk(new File(p), location, loaded, ctor);
    }

    private static int crawlAbsolute(Object location, Map<String, List<Object>> loaded,
                                     Constructor<?> ctor) throws Exception {
        String pwd = System.getProperty("user.dir", ".");
        String saves = System.getProperty("com.fs.starfarer.settings.paths.saves", "../saves");
        String mods = System.getProperty("com.fs.starfarer.settings.paths.mods", "../mods");
        Path base = Path.of(pwd).toAbsolutePath().normalize();
        int total = 0;
        total += walk(base.toFile(), location, loaded, ctor);
        total += walk(base.resolve(saves).normalize().toFile(), location, loaded, ctor);
        total += walk(base.resolve(mods).resolve("enabled_mods.json").normalize().toFile(),
                location, loaded, ctor);
        total += walk(base.resolve("..").resolve("mikohime").normalize().toFile(),
                location, loaded, ctor);
        return total;
    }

    private static int walk(File file, Object location, Map<String, List<Object>> loaded,
                            Constructor<?> ctor) throws Exception {
        int total = 1;
        add(loaded, ctor, location, keyFor(file, location), file.getPath());
        File[] children = file.listFiles();
        if (children != null) {
            for (File child : children) total += walk(child, location, loaded, ctor);
        }
        return total;
    }

    private static void add(Map<String, List<Object>> target, Constructor<?> ctor,
                            Object location, String key, String path) throws Exception {
        if (key == null || key.isEmpty()) return;
        target.computeIfAbsent(key, k -> new ArrayList<>())
                .add(ctor.newInstance(new File(path), location));
    }

    private static String keyFor(File file, Object location) {
        return normalize(file.getPath().replace(getLocationPath(location), ""));
    }

    private static String getLocationPath(Object location) {
        try {
            String type = typeName(location);
            Object path = get(location, "ResourceLocation_path");
            if ("DIRECTORY".equals(type) && path instanceof String p) return p;
            if ("ABSOLUTE_AND_CWD".equals(type)) return System.getProperty("user.dir", ".");
        } catch (Throwable ignored) {
        }
        return "";
    }

    private static String normalize(String path) {
        if (path == null) return "";
        if (path.startsWith("/")) path = path.substring(1);
        if (path.startsWith("\\")) path = path.substring(1);
        path = path.trim();
        path = Path.of(path).normalize().toString().replace("\\", "/");
        if (path.endsWith("/")) path = path.substring(0, path.length() - 1);
        if (path.endsWith(".")) path = path.substring(0, path.length() - 1);
        return path.toLowerCase(Locale.ROOT);
    }

    private static String typeName(Object location) throws Exception {
        return String.valueOf(get(location, "ResourceLocation_type"));
    }

    private static Path indexFile(RuntimeContext ctx) {
        return ctx.cacheRoot().getParent().resolve("file-index.idx.gz");
    }

    private static Object get(Object target, String name) {
        try {
            Field field = target.getClass().getDeclaredField(name);
            field.setAccessible(true);
            return field.get(target);
        } catch (NoSuchFieldException e) {
            throw new IllegalStateException("field not found: " + name, e);
        } catch (ReflectiveOperationException e) {
            throw new IllegalStateException("field access failed: " + name, e);
        }
    }

    private static List<FileIndex.Location> locationKeys(List<Object> locations) {
        try {
            List<FileIndex.Location> out = new ArrayList<>(locations.size());
            for (Object location : locations) {
                Object type = get(location, "ResourceLocation_type");
                Object path = get(location, "ResourceLocation_path");
                Object isMod = get(location, "ResourceLocation_isMod");
                if (!(type instanceof Enum<?> t) || !(path instanceof String p)
                        || !(isMod instanceof Boolean m)) return null;
                out.add(new FileIndex.Location(t.name(), p, m));
            }
            return out;
        } catch (Throwable t) {
            return null;
        }
    }

    private static Constructor<?> fileHandleCtor() {
        try {
            Class<?> cls = Class.forName(FH_CLASS, false, ClassLoader.getSystemClassLoader());
            for (Constructor<?> ctor : cls.getConstructors()) {
                Class<?>[] params = ctor.getParameterTypes();
                if (params.length == 2 && params[0] == File.class) return ctor;
            }
        } catch (Throwable ignored) {
        }
        return null;
    }

    private static boolean prefixOk(String filePath, Object location) {
        try {
            Object path = get(location, "ResourceLocation_path");
            if (!(path instanceof String base) || base.isBlank()) return true;
            Path file = Path.of(filePath).toAbsolutePath().normalize();
            Path root = Path.of(base).toAbsolutePath().normalize();
            return file.startsWith(root);
        } catch (Throwable t) {
            return false;
        }
    }
}
```

### B.1 事实（已由 controller 亲自 javap 核实）

- 安装的 `fr.agent.jar` 的 `Transformations` 把可读名映射为：
  - `com/fs/util/FileLoader$ResourceLocation` → `com/fs/util/C$Oo`
  - `ResourceLocation_type` → `super`
  - `ResourceLocation_path` → `Ó00000`
  - `ResourceLocation_isMod` → `String`
- `javap -p -classpath fs.common_obf.jar 'com.fs.util.C$Oo'`：
  - `public com.fs.util.C$o super;`（枚举）
  - `public java.lang.String Ó00000;`（路径，**可为 null**：`ABSOLUTE_AND_CWD`/`CLASSPATH`）
  - `public boolean String;`（isMod）
  - `public java.lang.Object Ò00000;`（额外字段，忽略）
- `com.fs.util.C$o` 的枚举常量名是 `DIRECTORY` / `ABSOLUTE_AND_CWD` / `CLASSPATH`（构造器把字符串传给 `Enum.<init>`），所以 `String.valueOf(enum)` 可读。
- FR 的 `isExcludedLocation` 还排除 `path == "../starfarer.res/res"` 的 `DIRECTORY`，不只是 `CLASSPATH`。
- 结论：按**字段类型形状**解析（唯一枚举 / 唯一 String / 唯一 boolean）是稳定的；可读名优先，形状兜底，仍失败则 fail-open。

```java
private record LocationFields(java.lang.reflect.Field type,
                              java.lang.reflect.Field path,
                              java.lang.reflect.Field isMod) {}

private static final ClassValue<LocationFields> LOCATION_FIELDS = new ClassValue<>() {
    @Override protected LocationFields computeValue(Class<?> type) {
        return resolveLocationFields(type);
    }
};

private static LocationFields resolveLocationFields(Class<?> cls) {
    // 1) readable names (fixtures / un-obfuscated dev builds)
    try {
        java.lang.reflect.Field t = cls.getDeclaredField("ResourceLocation_type");
        java.lang.reflect.Field p = cls.getDeclaredField("ResourceLocation_path");
        java.lang.reflect.Field m = cls.getDeclaredField("ResourceLocation_isMod");
        t.setAccessible(true); p.setAccessible(true); m.setAccessible(true);
        return new LocationFields(t, p, m);
    } catch (NoSuchFieldException ignored) {
        // fall through to shape
    }
    // 2) shape: exactly one enum, one String, one boolean
    java.lang.reflect.Field t = null, p = null, m = null;
    int enums = 0, strings = 0, bools = 0;
    for (java.lang.reflect.Field f : cls.getDeclaredFields()) {
        if (java.lang.reflect.Modifier.isStatic(f.getModifiers())) continue;
        Class<?> ft = f.getType();
        if (ft.isEnum()) { t = f; enums++; }
        else if (ft == String.class) { p = f; strings++; }
        else if (ft == boolean.class || ft == Boolean.class) { m = f; bools++; }
    }
    if (enums != 1 || strings != 1 || bools != 1) return null;
    t.setAccessible(true); p.setAccessible(true); m.setAccessible(true);
    return new LocationFields(t, p, m);
}
```
